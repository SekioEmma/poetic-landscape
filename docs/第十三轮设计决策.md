## 编码前方案

实际读取本地 `C:/Users/13398/.codex/skills/frontend-design/SKILL.md`，采用其“方案—对照任务审视—实现—截图批评”流程；技能是指令文件，没有虚报工具调用。主题仍是沿真实地理读古典诗文。

保留现有纸面、单层读案、全国省界与点选机制。重点新增西北的文化入口和关城类别，禁止为三处另造画框、照片占位或常驻介绍卡。

色阶沿用：纸底 `#F4F0E6`、净纸 `#FCFAF4`、正文墨 `#2E3430`、次级墨 `#60685E`、边界青 `#506553`、选择朱 `#8D5044`。沿用现有系统宋体回退，不新增字体下载，原文至少18px；短题名与正文有层级，工具与出处安静。

```
全国：   楼兰   [敦煌·2处]       江南与江汉组
区域：          玉门关 / 阳关    （近邻名单可关闭）
阅读：   地图上的选中题注        地名 + 篇名、作者
                                原文精确高亮
                                地点 / 沿革 / 底本
手机：   完整全国 → 下方单层读案，篇名作者及诗行进入首屏
```

《瑞鹤图》的空处与清晰物象转译为：文化点有轻重、普通省名退后；《听琴图》的主体与环境相邻转译为：选中题注仍在真锚点旁，读案保持一层。只借构图与笔线，不复制馆藏画或假造遗址平面。关城小图以夯土墙、门洞和残垣表达类别，避免给古关贴现代高楼或湖心亭图标。

审视：纸色是既定用户偏好，保留有依据；新增内容若堆成三张同样阴影卡，会使地图变目录墙，因此继续使用同一个地图与同一个阅读案。全国组名依真实成员，跨甘肃、新疆不写“敦煌”；低倍允许聚合，但名单必须覆盖成员。

## 实现后批评与修整

第一次看390全国页时，9处被原生56px聚合半径串成一组，空白虽在，东西部内容却无从分辨；这是入口密度问题，不需要再换纸色。把手机聚合半径收为32px，桌面仍48px，最终低倍为甘肃与新疆3处、江南与江汉4处、其余2处。分组来自真实点位，组名由真实成员生成；楼兰不冠名敦煌。对照 [修整前](screenshots/round13/c-national-390.png)、[修整后](screenshots/round13/delivery-cold-final390.png)。

区域倍打开西北组后，楼兰独立，玉门关与阳关先成敦煌2处，再能展开为两个独立锚点；必要近邻名单保留完整名称、地区与篇数。3个新增小图采用1.25px墨线，玉门关门洞／墙垛、阳关烽燧、楼兰残垣分别可辨，选中朱色与线重沿用既有规则。没有把关城画成湖心亭或现代楼台。

随后发现旧近邻名单关闭按钮使用负边距，实际截图中看不见；新标题行给关闭按钮44×44px空间。第一次修整又让名单与手机右下定位工具重叠，最终把名单右侧多留64px，最后实测名单右边314.29、工具左边326.29，间隔12px，关闭与Escape都可用。见 [最终名单](screenshots/round13/delivery-nearby-final390.png)。三条具体问题均来自运行图，不以CSS推测代替观察。

桌面 [玉门关关山月](screenshots/round13/delivery-yumen-1280.png) 仍是地图主、原文先行的一层读案；关城题注独立高于淡省名。手机 [楼兰](screenshots/round13/delivery-loulan-final390.png) 地名、篇名、王昌龄与至少首联进入第一屏；18px正文没有缩小。旧长地名、长题名也实测，无横向溢出。1280／1000／390地图可用区宽高分别约852×624、596×704、374×379；来源、工具、画与照片沿用原层级。

自评没有用三张同款卡扩容，也没有泛化宋画为飞鹤、污渍或浓墨。全国仅省界资料，高倍有大块留空是资料尺度限制；没有凭空补遗址街道、路线或大画。借宋画构图与细笔层级的具体位置为真实点题注、关城小图与原文阅读留白；不声称复原赵佶笔墨。整体艺术终审仍由用户／后续独立验收判断。
