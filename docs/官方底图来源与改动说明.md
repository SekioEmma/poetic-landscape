- 静态JPG／EPS不是可直接使用的WGS84瓦片。先核验投影、坐标参考与配准信息；没有依据，禁止用图片四角经纬度直接拉进MapLibre导致整图变形、错位。
- 若先采用原图＋独立页面标记，标记以原图像素／归一化位置记录，并说明这是总览展示锚点，不冒充测绘坐标。位置须逐项核验，响应式缩放与原图保持同一变换。此路径是图片总览，不算L7地理底图验证。
- 若采用投影转换或栅格配准接入L7／MapLibre，记录转换依据、参数、软件、误差检查和输出文件，将其归为地图处理改动；完整原图保留用于对照，成品仍待审核确认。
- 全国总览与局部地图可以采用不同的数据呈现方案，但切换与返回必须清楚，初始化和销毁可控；不要为了坚持单一渲染器而擅自扭曲原图。架构变化写入记录，避免同时挂载无必要的多个WebGL地图。
