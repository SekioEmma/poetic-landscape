# 第九轮宋画样板与文化题注规范

2026-10-07。接续第八轮已建立的地图＋读案空间结构。保留素纸、洁纸、浓墨、次墨、青绿、朱色及系统宋体；不改变常态地图预算，也不恢复大底案。

## 1. 主张与依据

地图提供可探索的地理关系；文化地名成为近景信息，诗文为读案主体，画作提供与当前篇目相合的观看细节。视觉记忆来自精微的主物象与清润设色，纸纹承担材质。

[大都会《竹禽图》](https://www.metmuseum.org/art/collection/search/39936)本次已读取；从细察、传神与绢本设色出发，转译为枝、叶、鸟、舟亭的形态差异和轻重墨线，不要求照抄古画。故宫《听琴图》《芙蓉锦鸡图》延续前期参考，本次检索可读、直开超时，归属遵循馆方讨论。

院体转译落实为：主物象轮廓清晰、形态有观察依据、设色层次能看出结构，空处与精绘相互支撑。湖景远处可轻，近处不能都靠晕染；纸面温润，原文区域清净。

## 2. 文化题注层级

| 层 | 视觉职责 | 检查 |
|---|---|---|
| 官方原图 | 地理背景、边界与地名依据 | 字节／几何／锚点不变；本轮不擦注记或海域线、不增加AI地理 |
| 当前地点 | 明确“正在读这里” | 稳定小锚点＋清楚地名；选中色一处主位，不叠加光圈、底框、重投影 |
| 其他文化点 | 可发现、可比较 | 墨色／青绿地名；类别图标辅助；44px热区与可见焦点保持 |
| 地域组 | 解决真实屏幕密度 | 地域名与数量清楚，少装饰；打开仍逐项可读，不移动真实位置 |
| 题签与工具 | 阅读与探索入口 | 与原文／点位各自明确；不新加永久说明条挤正文 |

试验选点初始尺度最多两档，在同尺寸、同地点、同图幅记录中比较。现有1.85／2.1并非视觉不可变常量；目标是文化地点及地域关系清楚，原图注记不因默认聚焦而过度放大。自动选点仍必须把真实锚点和名称放进安全区，用户主动放大与对照原图不受限制。坐标数学、手动接管、关闭恢复不变。

不要求放大后背景城市都变不可读；PNG的文字仍属于单一位图。美术判断同时看全国总览与真实选点，不用最漂亮的一帧代替所有状态。

## 3. 两个有明确文意的画面

### 湖心亭雪夜：主样板

取张岱原文的远亭、孤舟、人影和天地空处。主物象做细笔：舟与篷有结构、疏枝有生长关系、亭阁不均匀描成工程线稿。淡墨与少量清润设色托住主体，前景枝叶只用少量细节；保持雪与湖面的疏阔，不放铺满页面的重山峦。

是一幅原创意境表达，非古建复原。画中不生成诗句、印章、署款；题名／文字由HTML表达。正文先于解读／画，现有局部地图与真实照片入口不改变。

### 钱塘春行：辅助样板

只关联白居易《钱塘湖春行》：新柳、早春浅草、少量春鸟与疏湖岸，体现春色初生和观看的节奏。与雪夜样板共用细笔、墨色和设色质量，不复用雪山或冬枝。主体精细、其余简洁，图中没有文字／地图／精确建筑复原。

苏轼晴雨诗可先不配画；以清楚的诗行和留白完成阅读，不为“每篇都有图”错误共享季节。更新小型作品—绘画映射即可，不建立CMS或把原文复制进资产元数据。

## 4. 在真实显示尺寸成立

- 常态案画宽约280–420px；手机自然缩放，无多余的大画容器。画面在该尺寸可识别主物象和细墨关系，大分辨率资产预览不能代替实页效果。
- 静态PNG／WebP可用；需要透明时直接生成／编辑真实透明通道。检查素纸和洁纸背景下的白边、彩边、接缝，不能用CSS模糊掩盖。
- 保留原图及历史画作。记录实际工具、提示词、生成／编辑日期、输出路径和人工选择；页面标明AI辅助原创意境图，与照片区分。
- 最多两幅最终资产，每幅最多两版候选加一次必要编辑。第一幅若仍明显不成立，停在主样板修订，辅助图不批量强上；报告不能以生成次数称完成美术。
- 图标仍用原生SVG，不把大画缩成所有地点的新按钮；无需增加六幅地点插图或主页封面。

## 5. 美术验收口径

原文内容不变、地图预算不变、操作不退步。在同一真实阅读状态查看旧图与新图：主物象的形态、细墨轻重、设色层次、纸面衔接、与诗文对应至少有可指认的改善。单改透明度、字号或纸黄程度不作为通过依据。

文化题注看1440总览、1000选点、768竖屏和390手机；画作看实际滚到画的手机与桌面正文，同时核验从原文到画、到资料的顺序。若全国原图密注记仍无法满足观感，说明素材缺口；不能由样板画通过顺带授予地图资产通过。
