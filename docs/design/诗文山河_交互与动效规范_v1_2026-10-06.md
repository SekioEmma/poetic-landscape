# 诗文山河：交互与动效规范 v1

2026-10-06，第六轮执行基准。配套宋代美学原规范、执行补充v1.1与总计划v2.1。界面继续采用纸色、宋体与宋画；Apple参考用于操作逻辑、反馈、状态连续性和动效品质。

## 1. 原则落到这个项目

本次实际阅读Apple官方[Motion](https://developer.apple.com/design/human-interface-guidelines/motion)与[Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback)页面。官方强调动效应有目的、反馈应符合动作预期、允许中断、不为高频操作增加无意义等待，状态反馈贴近相关对象。下文时长和状态规则是本项目的设计选择，**不是Apple规定值**。

- **动作与结果相邻。** 点地点立即给选中反馈；点作品立即确认当前篇；资料加载只在相关内容区显示状态。
- **返回保留来处。** 回到诗文还在刚才读的位置，退出阅读回选点前的地图；开目录和出处不偷偷改变相机。
- **稳定的操作骨架。** 地点名、返回／展开和阅读标签位置有规律；正文长短和绘画显示不迫使标签随意跳位。
- **随时可接管。** 新选点覆盖旧选点；拖动接管镜头；关闭发生在打开尚未结束时也应成立。动画期间不禁用整站。
- **轻而清楚。** 小反馈先完成，不用“成功”通知打断每次选点；普通文本与可操作文字仍有足够对比。
- **动态可减弱。** OS减少动态与站内静观一致生效，状态语义、焦点和可用性不依赖动画。

## 2. 状态与返回协议

| 操作 | 必须保留／改变什么 | 焦点与滚动 |
|---|---|---|
| 首次选择地点 | 保存探索相机与筛选；确定地点／默认作品；地图定位当前地点 | 新阅读案地点标题聚焦；新内容从起始位置显示 |
| 同地点换篇 | 地点、镜头不变；题名／引句／解读／原文高亮／出处原子更新；沿用全文展开策略 | 切换控件节点稳定；若采用篇名聚焦则preventScroll并有可见焦点。首次到某篇起始位置，回已读篇恢复该篇 |
| 诗文→此地→诗文 | 保存各标签阅读位置；局部首次按需加载，重入保留手动局部镜头 | 标签按钮保持位置与焦点；回诗文恢复原文开合及内容锚点 |
| 诗文→沿革→诗文 | 地点和作品不变，不触发地图重新聚焦 | 各标签各有滚动位置，切回不归零 |
| 半屏↔展开 | 内容、作品、标签不变；保留当前位置；地图保持当前地点身份 | 优先保持内容锚点的屏幕位置，空间不足时合理夹取；不得归零。原文所在容器仍只有一个 |
| 开目录／出处 | 筛选、相机、阅读位置不变；出处展示当前作品；覆盖型目录与来源互斥 | 最上层负责焦点与Esc；关闭回入口。桌面并列目录不做全局焦点锁 |
| 开地图分组 | 标题说明当前是邻近地点选择，不改变相机 | 键盘打开进入首个选项；Esc回分组入口；选项激活进入对应阅读案 |
| 关闭阅读／返回中国地图 | 恢复选点前探索相机，清理待执行镜头动作，恢复探索筛选 | 从地图进入则回仍存在的原地图入口；从目录进入则回该结果或寻诗文入口；入口已消失时提供合理后备 |
| 看全国 | 明确复位全国相机；不伪装成关闭阅读；来源对照不改变点位 | 焦点留控件，视野变更有清楚反馈 |
| 进入／退出局部 | 保留局部镜头及进入局部前的全国阅读视野 | 回诗文时恢复阅读期间的全国视野；只有退出阅读才恢复最早探索视野 |

阅读记忆键至少区分placeId／workId／tab；当前浏览会话内保存即可，无需localStorage、账号或数据库。优先记录正文元素标识＋相对偏移，无法实现时保存scrollTop并处理布局变化、夹取和同位置恢复。全文开合、画的存在与面板尺寸变化都可能改变高度，不能盲目回放旧像素。

长文开合后同一触发入口应仍可找到；折叠把正在阅读的内容移除时，将视线合理带回“展开完整原文”入口。不以强制scrollIntoView制造每次操作的跳动。

## 3. 动效矩阵

| 场景 | 建议起点 | 空间逻辑与约束 |
|---|---|---|
| 按压／选中反馈 | 80–120ms；视觉选中立即生效 | 文字／小色阶响应，避免所有按钮弹跳缩放 |
| 阅读案进入／退出 | 220–300ms | 桌面从右侧进出；移动端从底部进出；位移短、透明变化克制。退出仍能结束与清理 |
| 手机半屏／展开 | 280–360ms | 同一张纸面改变占用范围，标题与阅读内容有连续性；不能缩放整块文字冒充真实布局 |
| 目录／资料浮层 | 180–240ms | 保留来源入口的空间关系；遮蔽与焦点状态同步；退出中的隐藏层不接受输入 |
| 换篇／标签 | 首次尝试即时更新或100–160ms轻淡入 | 高频操作不反复整张阅读案滑进滑出；焦点、滚动与来源一起更新 |
| 全国镜头聚焦／返回 | 继续以现有420ms为基线，必要时300–450ms微调 | 地图与文化锚点全程同步；新操作覆盖旧目标；用户拖动立即接管 |
| 局部加载 | 真实加载状态，完成即呈现 | 不人为补足动画时长；失败就地给阅读／重试出口 |
| 静观／减少动态 | 去掉位移和持续过渡，即时状态更新 | 无依赖动画end的业务逻辑；原文、焦点、滚动和恢复仍正确 |

曲线先选择一组克制的ease-out／ease-in-out。只有现有方案达不到连续切换需求才引入动效依赖；无需为了“像苹果”引入大库。优先transform／opacity；高度过渡若采用实际布局动画，必须检查重排与镜头影响。禁止动画期间每帧触发地图重新fit／聚焦或销毁重建L7实例；必要时使用容器合成过渡并在布局稳定点resize。

## 4. 宋画呈现与现代可用性共存

### 具体构图

全国图为主卷，阅读为侧页／底部展开的同一纸案。全国背景、地名题注、阅读底色和出处都使用同一纸墨层级。边缘以微弱材质／色阶和留白区分，避免容器硬线、重阴影主导画面；这不等于一律加大圆角。

阅读固定骨架：返回／展开工具→地点与区域→稳定的诗文／此地／沿革入口→当前内容。诗文内：篇名作者与换篇→真实引句→画与题注→短解读→完整原文。先在手机半屏验证能识别地点、作品与标签，再定画高；画不能挡住换篇或正文入口。当前标签迁移到更稳定的位置是允许的，不要因第五轮已有CSS坚持旧顺序。

### 赵佶主轴如何被看见

沿用既有馆方研究与[宋代美学执行补充v1.1](G:/project/数媒/design/诗文山河_宋代美学执行补充_v1.1_2026-10-06.md)：细察物象、轻重墨线、局部层次设色、画面疏密与题诗关系。赵佶相关院体不是“所有颜色很淡”的同义词；主物象应有可辨的笔墨与体积。纸感是界面材质，绢本作品的载体说明照实保留。

先用现有湖景验证组合。若实际240–420px尺度仍只像泛化水彩或树亭细节混成一团，允许一次有具体目标的局部资产修订；不得直接扩成六幅／十二幅新图。黄鹤楼用题诗与留白成立，没有合适画就保留无画状态；不配错湖景或复活工程线稿。

纹理静止、低对比、无重复接缝；文字区清净。现有六色与宋体回退继续保留；不靠全站淡化、压窄伪瘦金体、堆印章解释风格。控件14px可读、触摸命中区至少44px；真实文本保留HTML。外链↗只用于外链，不用于页面内换篇。

全国地图原始栅格不做模糊抹除、AI补画、边界变形或改变真实岛屿。可追溯的二创沿用用户授权。通过文化题注的字号／墨色／留白、工具退后、选中锚点与关联阅读改善层级；不得靠将底图变成几乎不可读的淡影来掩盖问题。栅格能力确实不足时如实保留G2未通过，并说明所缺图层资产。

## 5. 验收连续过程

必须看：选点途中改选、开案途中关闭、半屏展开途中反向、连续换篇、长文切标签往返、分组与来源叠加、手动拖图接管镜头。稳定终态截图无法证明这些情境通过。

保留三尺寸同状态截图；另交付至少一段可核对上述动作的连续录屏，或带时间戳的连续帧／状态轨迹。记录实际硬件与浏览器、发生的停顿及修订；性能用本机实测帧间隔／长帧／long task等可用证据，不预填“稳定60FPS”。实机双指另记，不用390px浏览器尺寸替代。
