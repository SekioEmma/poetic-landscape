# 诗文山河：地点阅读信息架构与版式规范 v1

> 面积与断点更新（2026-10-07）：本文件第5节旧宽高建议已被[地图与读案空间规范v1](G:/project/数媒/design/诗文山河_地图与读案空间规范_v1_2026-10-07.md)覆盖。内部原文、篇目、地点结构与记忆继续有效；勿再次按64–68dvh实施默认选点态。


2026-10-07，第七轮实施基准。依据第六轮真实页面与现有6地点8作品。该规范修正旧动效规范v1及第六轮任务中的阅读顺序、固定作者栏与原文默认折叠规则；阅读记忆、浮层优先级、可打断动效、相机分记继续保留。

## 1. 先定义选点后的三件事

用户选地点后，需要回答：**这里有哪些作品？我正在读哪一篇？这处地方是什么？**

选点默认进入诗文，作品选择与地点介绍是明确入口。把诗文原文作为主体，诗意解读和绘画作为辅助；不用摘句、画和长解读把原文入口推到下面。

第六轮稳定了导航，却把固定区域做得过重。390×844的黄鹤楼阅读案422px高，工具45px、固定标题／三标签／作者选择约144px，正文视口约189px；原文折叠入口在y≈929px。原方案的固定骨架需要精简，不能继续要求所有层级都吸顶。

### 对三个候选布局的选择

| 方案 | 判断 |
|---|---|
| 继续摘句／画／解读／展开原文 | 更适合导览卡，原文仍难读，不采用 |
| 地点资料、诗篇目录、原文三列并排 | 宽屏可容纳但层级过多，地图再占一列后过密；手机迁移困难，不采用 |
| 地点上下文＋两个视图＋紧凑篇目入口，原文优先 | 采用；保留地图语境，明确正文与辅助内容，支持短诗和长古文 |

## 2. 采用的骨架

```text
选点后的阅读案
  返回地图                    展开阅读
  黄鹤楼                      湖北 武汉
  [诗文] [地点]              [诗篇 2篇 ▾]
  ───────── 以下为唯一正文滚动区 ─────────
  黄鹤楼                     ← 当前篇名，正文主标题
  崔颢  唐

  昔人已乘黄鹤去，
  此地空余黄鹤楼。
  ……完整原文……               ← 默认呈现，不先展开

  诗文与此地                  ← 原创短解读，原文之后
  ……
  可选意境画／题注            ← 原文之后，不抢阅读首屏
  底本与版本                  ← 就近资料入口
```

地点视图：**此地风物／简介→必要的现代与古典关系说明→文化沿革→可用的局部地理／真实图景→地点资料来源**。沿革成为同一页的内容节，不再单独占一个顶层标签。没有图片或局部图的地点正常显示已有资料，不画空占位框。

保留一个正文滚动容器。工具、简洁地点上下文、两视图导航固定；篇名作者进入正文，去掉常驻作者按钮栏和常驻“原文与地景，各有出处”页脚。底本与版本入口在当前作品末尾，全站原图／资料入口继续保留。

## 3. 多作品：用篇目识别作品

- 一篇作品不出现无意义选择器。
- 多篇在导航行显示“诗篇 2篇”等入口；展开列出**完整篇名＋作者／时代＋当前选中状态**。不能只靠作者区分，后续同作者多篇也适用。
- 列表不做一组大卡片，不截断长篇名为省略号。390px可自然换行，作者为次行，单项至少44px命中区。
- 当前作品篇名在正文只显示一次，作者／时代只显示一次。不再另放与正文重复的摘句大字号引文。
- 控件节点稳定；选择后焦点回篇目入口或明确正文标题，不能落body。新篇从起点，换回已读篇恢复记忆；来源、高亮、解读和原文同一次选择一起更新。
- 不引入独立文章页面／路由／新模态阅读栈。选择器是轻量popover，可用合适原生能力实现；焦点、Esc、点击外部与原有来源／目录遵循最上层规则。

## 4. 按文体排原文

| 文体／现有样例 | 排版 |
|---|---|
| 七绝：李白送孟浩然、苏轼饮湖上、枫桥夜泊、泊船瓜洲 | 四句四行，完整呈现；题名作者与诗行同轴。短诗不用展开开关 |
| 七律：黄鹤楼、钱塘湖春行 | 八句八行，联与联适度区隔；不把整联挤成一条长句，也不把末字挤到下一行 |
| 歌行：茅屋为秋风所破歌 | 沿用底本四段，段内按核定诗句分行，保留句长变化；不强制七字对齐 |
| 古文：湖心亭看雪 | 保留四段与完整标点，连续段落阅读；首行缩进与行宽协调，不切成诗句 |

**全部现有作品默认显示完整原文，通过正文区滚动读完。** “展开阅读”改变阅读空间，不是打开另一份正文；不再默认折叠原文。第六轮的`originalOpen`状态可退役，但会话阅读锚点与作品记忆保留。

诗句与古文的排版元数据应独立于公版原文：可用workId映射文体、paragraphId与分行偏移。原始paragraph文本、ID、版本、标点和relation.highlight不得为了排版而改写。不简单按每个逗号把所有作品切行；未来词体必须有分阕／句读元数据，不由字数猜文体。

高亮仍对应确切关联原句；跨行允许多个视觉mark，必须覆盖同一连续文本，不能把DOM节点数量当作文本正确性的指标。用轻墨色／轻底色，不做粗框、药丸背景或整段红字。

## 5. 空间与信息密度

以下是初始设计约束，以实际页面验证微调；不是把像素全部锁死。

| 场景 | 初始建议 | 质量检查 |
|---|---|---|
| 桌面1440×900 | 常态阅读案约520–580px；原文有效宽约450–500px；展开到700–780px，古文正文仍限制合理行宽 | 选点后当前题名作者与短诗／七律原文可读，原图仍有操作区；不沿用404px定宽及450px相机硬编码 |
| 平板768×1024 | 底部阅读案约60–66dvh，保持地图语境；展开沿用近全屏单一纸案 | 不用宽度增加掩盖高度不足；真实正文视口足够，长古文不被画压到首屏之外 |
| 手机390×844 | 初始阅读案约64–68dvh；固定工具＋地点上下文＋导航合计目标≤132px，无永久44px口号页脚 | 七绝四句进入初始正文可视区；七律至少连续四句，展开后八句可读；古文第一段完整可见 |

地点上下文约20–22px，篇名22–26px成为阅读主标题；作者／时代14px，操作14px，原文18–20px；诗行约1.75–1.9行高，古文约1.9–2.0，解读16px。不要把正文缩到14px以凑首屏。普通文字不得淡到难读。

手机未选点时仍是全国地图主界面；选点即进入阅读意图，适度增加阅读高度。明确“返回地图”关闭阅读、“展开／收起阅读”改变纸案面积，不能把64–68dvh继续叫“半屏”。同一纸案保留阅读位置，不另开一层全屏modal。

阅读案尺寸和地图安全区统一由实际DOM区域计算。新增宽度不能只改CSS后让地图继续按450px避让；验收锚点、标签、目录避让与恢复视野。

## 6. 地点介绍与局部地图的关系

读“地点”先看到简介和沿革，切这个视图**不自动切换地图引擎或镜头**。有局部地理资料时，提供明确“查看局部地图”入口，才按需加载／显示既有L7；退出局部只改变图面，不关闭当前阅读。保留探索／全国阅读／局部手动镜头的分记。

真实照片仍使用已有本地文件与署名许可；意境画与照片用途不同，分别标注。无资料不新增假实景或历史复原。沿革是有来源的短介绍，现有材料没有具体年份时不改造成虚构年表。

## 7. 宋画语言落实在哪里

保留纸墨配色及宋体回退。用题名、题跋式短解读、原文与画的疏密关系组织册页；主视觉先是文学文字，画在原文后与题注对应，用户不读图也能完整读文。宋画留白来自构图主次，不是给每个区域固定一大片空白。

延续赵佶相关研究中的细察物象、墨线轻重与层次设色。既有湖景可复用，不要求本轮重新生成图；让窄诗行、适度留白和纸材衔接先成立。黄鹤楼无合适画则保留无画的诗页，不能补错湖景或工程线稿。控件靠字号、文字和选中反馈组织，不堆细框、分隔线或印章。

## 9. 本次样稿自审记录（不作为生产验收）

实际浏览器查看1440、768、390样稿。1440常态阅读案550px、正文视口624px；390固定区约123.7px、正文433px，无横向溢出，七律8行、李白4行可直接阅读。768古文第一段完整可读；六处默认作品与《钱塘湖春行》在DOM内连接后的文本与原始paragraph逐字一致，李白四句亦对照现有底本。
