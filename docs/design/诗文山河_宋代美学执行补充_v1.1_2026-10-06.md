# 诗文山河：宋代美学执行补充 v1.1

2026-10-06。与[原视觉规范](G:/project/数媒/design/诗文山河_宋代美学与赵佶视觉规范_v1_2026-10-05.md)配套；第五轮发生冲突时，以本补充与第五轮任务书为准。保留原配色和赵佶主轴，调整此前过度约束SVG、线宽与资产数量的做法。

## 设计命题

让中国地图与地点阅读像置于素纸上的诗画册页：地图负责地理，画作负责感受，题诗负责将二者连起来。赵佶相关绘画的重点放在细察、传神与层次设色；纸感承担温润的界面材质。正文依然是可以选择、复制的清晰文字。

“柔和质朴”是用户对产品的要求，不把赵佶的全部作品概括为寡淡，也不把绢本绘画说成宣纸水墨。当前小景的均匀建筑描边不再作为精绘参考。

## 先看具体作品，再做转译

本次重新打开故宫《听琴图》与大都会北宋研究及《竹禽图》条目。故宫《芙蓉锦鸡图》入口本次超时，保留为前期研究参考，不新增本次核验声明。

| 参考与本次证据 | 需要落实的画面选择 | 实现后的反向检查 |
|---|---|---|
| [故宫《听琴图》](https://www.dpm.org.cn/collection/paint/231409.html)：馆方介绍其设色、庭园物象与题诗，亦讨论画院创作归属 | 物象集中、树石有组织，墨线与色面相互支撑；题名和诗句与画面形成空间关系 | 去掉所有“宋代”文字后，画面是否仍有细致的物象、轻重关系，而非只剩空背景与线框 |
| [大都会《竹禽图》](https://www.metmuseum.org/art/collection/search/39936)：馆方列为赵佶，绢本水墨设色，介绍对鸟与竹的观察和生命感；页面标Public Domain | 以疏密不同的竹叶、枝干和一处精细主物象建立节奏；主物象精细，其余轻 | 是否每片叶、每段线都机械重复；是否物象只像UI符号放大 |
| [大都会北宋绘画研究](https://www.metmuseum.org/essays/northern-song-dynasty-960-1127)：讨论自然观察与诗意表达 | “诗中地点”的感受从对应诗句出发；湖心亭以远亭、舟和雪后空处为主题 | 装饰是否与诗句关联；是否出现无缘由的鸟、印章、花或卷轴 |

上述是当代界面转译，不照搬古画构图。故宫作品归属采用馆方讨论口径；不得把画院归属争议写成绝对的亲绘结论。公开观看不等于允许复制全部影像；本轮优先原创。若使用大都会公开资产，记录具体图片及许可页面、下载日期和改动，不能称原创。

## 材质与绘画的具体要求

| 层 | 做法 | 不通过的表现 |
|---|---|---|
| 纸底 | 原纸色基础上加入细微、方向自然的纤维与低频色差；阅读文字上方保持清净；静态本地材质 | 平铺均匀噪点、明显重复接缝、划痕状斜线、浓黄陈旧纸 |
| 画作 | 细墨轮廓有主次；叶、枝、舟、亭为实际物象；淡设色有叠层与体积，精细集中在一处 | 建筑工程线稿、图标放大、等粗机械线、只填一块淡绿后宣称工笔 |
| 画面与纸底衔接 | 图画像落在同一张纸上，以自然留空或真实透明通道融入；使用独立本地资产 | 一张白色矩形图贴在米黄卡片上，或用CSS模糊涂掉画的边缘 |
| 阅读案 | 纸面底色、边缘和空间区隔适度；控件通过文字、留白与状态组织 | 四边硬框、可见重阴影、印章重复堆叠、强行加圆角当柔和 |
| 点位与选中 | 小而清楚的锚点、紧邻的地名，类别图标退居辅助；一套明确的选中提示 | 菱形、红底线、粗图标、白卡、额外红点同时竞争 |
| 地图 | 边界、点位与数据清楚；色调与纸底协调；局部真实水岸上使用细微设色层次 | 在生成图片里重画中国边界，或靠重噪声和模糊隐藏地图内容 |

不固定纹理瓦片为256px，不固定画作必须SVG，不用文件大小或节点数判断细腻。静态位图、精细SVG与混合资产均可；决定依据是在240–420px实际显示宽度和普通缩放下的效果。纹理必须静止且不拦截鼠标／触摸。正文对比度、操作焦点和可读性继续保留。

## 湖心亭样板

一幅原创意境画，取远亭、轻舟、疏岸与雪后空处；建筑不画精确古建复原。设色低饱和但有层次，不能只有轮廓。题名、作者、关联句、作品切换和阅读标签由HTML呈现；画中不生成文字、署款、印章或地图。

先在现有阅读案实际尺寸中试作，再决定是否替换首页小景。无需同时生成黄鹤楼和其他地点的全套插画。湖心亭效果成立后，其他地点先统一控件和阅读层级；旧线稿若明显破坏统一性，可暂时撤下装饰性展示，不影响资料和入口。

可用 `imagegen` skill 与内置图像生成工具制作新的绘画资产，记录实际提示词、所用工具与保存路径，标为AI辅助原创意境插画。生成结果必须目视审查并融入页面；使用工具不是通过条件。既有类别SVG小图标继续在原生代码中调整，不用图像生成工具替换一整套交互图标。

标题继续保留宋体回退；只有字库许可和网页嵌入范围明确时才接入瘦金体。不能把系统宋体压窄、变斜或伪加粗后称瘦金体；字体问题不阻塞本轮。

## 实际截图的五个判断

1. 第一眼是地图、被选地点和诗句，背景纹理及工具退后。
2. 去掉“宋代／原创”等说明，画作仍能看出细察的物象和浓淡设色。
3. 画与纸底有连续感，纸质在适当尺度能感知，文字没有噪声。
4. 手机不用越过长插画才能换作品，阅读与地图不重复堆同一段诗。
5. 同一状态与第四轮对照，能指出至少两处真实的材质／绘画改进，而不只是颜色和字号变化。

其中任何一项仍明显失败，就在报告中写“美术样板未达标”，继续有限修整；不得用构建成功、skill已读、增加SVG数量替代视觉结论。
