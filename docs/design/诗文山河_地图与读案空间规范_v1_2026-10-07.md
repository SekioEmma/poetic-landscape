# 诗文山河：地图与读案空间规范 v1

2026-10-07，第八轮设计基准。**地图是持续可探索的主界面，阅读案是可收起、可加宽／加高的伴随空间。** 本规范覆盖第七轮阅读规范v1的第5节面积数值和“选点即占64–68dvh”的要求；原文、篇目、地点信息顺序及阅读记忆继续保留。

## 1. 参考与设计推导

实际观察[Google Maps西湖页](https://www.google.com/maps/search/?api=1&query=West+Lake+Hangzhou)的窄详情栏、独立正文滚动与收起入口；[Google Places UI Kit](https://developers.google.com/maps/documentation/javascript/places-ui-kit/place-details)区分紧凑／完整信息，并推荐其完整组件250–400px宽；[Material底部面板规范](https://m1.material.io/components/bottom-sheets.html)说明地图可与持续详情共同操作、大屏可把底部详情转为侧边空间。

下面的断点、比例和状态是本项目的设计决定，不是Google强制规则。只借用空间与操作逻辑；纸墨与宋画语言、右侧读案、官方地图来源不改变。

## 2. 三种阅读空间，两个独立操作

| 空间状态 | 意义 | 地图与内容 |
|---|---|---|
| 收起 `collapsed` | 暂时看地图，保留当前地点／作品 | 小题签保留地名、当前篇目和“继续阅读”，不展示被裁半截的原文；地图仍能拖缩和改选 |
| 常态 `reading` | 选点后的默认阅读 | 横屏窄侧案，竖屏工作区约45–50%高；完整原文已在单一正文里，可滚动读完 |
| 专注 `focused` | 用户明确请求更大的阅读空间 | 横屏侧案适度加宽，竖屏接近工作区全高；仍是同一篇、同一阅读案，不新开模态文章 |

未选点另为探索状态，不把它当第四种阅读空间。建议一个受控枚举表达空间，替换/派生现有expanded，不叠加三个相互冲突的布尔值。

**收起读案≠关闭地点。** 收起保留地点、作品、视图、锚点、手动地图视野，继续阅读恢复；×／“返回地图”沿用关闭阅读和恢复进入前探索视野的语义。若工具行改为“收起读案 / 展开阅读 / ×”，×须有清楚的“关闭地点阅读并返回地图”可访问名称。不要再加一整行面积按钮。

专注态的“恢复分屏”回常态；常态“展开阅读”进入专注。收起题签内“继续阅读”回常态。点选另一地点进入该布局的常态，最后一次选择优先。目录按作品搜索选择后显示对应篇，不能因新增状态丢掉preferredWork。

Esc仍遵守篇目浮层→目录／出处→阅读案的既定最上层优先级，不让底层地图抢先响应。退出阅读需取消动画、清理模式和不可见控件，旧R01必须保持修复。

## 3. 响应式按可用空间，不按设备名称

统一计算工作区：视口扣除真实页头及必要安全边距；底部案比例针对工作区T，不能继续针对整个100dvh。

侧栏条件的初始方案：**W≥1100，或W≥800且W/H≥1.15**。实施中以文字可读和地图预算校正，但1000×750、1024×768必须为侧栏；768×1024为底部案。CSS、App覆盖模式、全国安全区、L7控件、阅读动画必须共享同一布局判断。

| 场景 | 常态 | 专注 | 最低地图预算 |
|---|---|---|---|
| 1440×900 | 右案约400–420px | 约560–640px | 常态可用图面宽≥工作区宽55%，目标约65% |
| 1280×720 | 右案约380–400px | 约540–620px | 常态图面宽≥55%，不把560px当默认 |
| 1000×750／1024×768 | 右案约340–360px | ≤可用宽度60%，正文有合理行宽 | 图面仍保有连续纵向空间，宽≥55% |
| 844×390横屏 | 窄侧案约320px，页头紧凑 | 可占更大空间但可一键恢复 | 常态地图宽≥50%，控件不得被页头／纸案挡住 |
| 768×1024竖屏 | 底案约45–50%T；案宽可限制约600–640px并居中 | 约90–96%T，正文宽不随案无限增长 | 案上方有效地图高度≥50%T |
| 390×844／360×800竖屏 | 底案约45–50%T，全文滚动阅读 | 约90–96%T | 案上方有效地图高度≥50%T |

数值是原型起点，实测验收预算优先；边距、页头和固定导航都必须计入。短高度底部布局若不能同时提供约220px正文视口与地图预算，默认使用约88–136px的收起题签，明确给出阅读入口；不能压小字体、只露半个正文窗口来硬凑。

收起态：横屏题签约240–300px宽、88–120px高；手机约88–136px高，标题／篇名／继续入口自然换行。名称和篇名不因长度硬截断；常态和专注都是完整原文，不新增“展开原文”折叠。

## 4. 阅读案内部保留，留白按内容安排

- 保留诗文／地点两视图、稳定篇目选择、篇名作者在正文、唯一正文滚动区、原文先于解读／图／资料。
- 常态侧栏左右内距约24px，移动约20–24px；原文18–20px，操作／作者≥14px。长题名自然换行，不挤压地图来追求单行显示。
- 古文约18–24字有效行宽，专注时适度增加；七绝／七律保留句行与联间节奏。空白在联间、题名与正文间服务阅读，不留一整块与内容无关的右半屏。
- 手机常态至少清楚呈现篇名、作者和连续诗行／首段开头；完整原文通过正文滚动到达。不得重新规定“所有七律八句必须首屏可见”，也不得给全文加折叠开关。短诗能完整进入首屏时优先做到。
- 题签小、篇名明确、浓淡墨分层；工具不做一排大胶囊、重投影或额外卡片。纸边可轻柔，材质静态低对比，避免毛边遮文字。承接赵佶题诗与主体相邻、主从明确的构图思路，不声称这样便完成工笔资产体系。
- 不用巨幅假画、无来源照片、重复诗句或新增信息块填空。本轮不制作新绘画资产、不改底图颜色，集中完成空间结构与有限纸案修整。

## 5. 地图安全区与相机

把实际地图矩形扣除页头、案、目录、工具和必要边距，得到一个用于选点定位、题注避让与分组列表的主要可用矩形。侧案在右则按水平避让，底案则按垂直避让；判断来自真实布局类型和尺寸，不能使用`innerWidth<=1024`猜。

同步改全国OverviewViewport和局部L7适配层。选中锚点及名称留在可见安全区，工具按钮可实际操作；不移动真实锚点、不改矩阵坐标语义。空间切换可在已选点将被遮住时做最小必要平移，不能每次收起都重置缩放。用户拖图可打断程序过渡；收起／恢复不得覆盖手动探索；关闭才按既定约定恢复选点前相机。

一次布局变化使用最终真实尺寸完成避让，避免ResizeObserver反复自动定位形成跳动。转换／退出期间禁止不可见控件收焦点；布局稳定后检查数据投影和题注，而非仅看CSS矩形。

同一地点／作品／视图的阅读锚点在常态、专注、收起、旋转／resize之后保持上下文；宽度改变造成行数变化时恢复语义锚点，不能只存一个scrollTop硬套所有尺寸。局部地图仍按需创建一个L7／MapLibre组合实例，收起／专注不重建引擎。

## 6. 实页验收

先以黄鹤楼（短诗／多篇）、湖心亭（古文／局部）做真实页面样板，再复用至6处；杜甫长歌、西湖长题名、寒山寺长地名必须抽查。至少测1440×900、1280×720、1024×768、1000×750、768×1024、390×844、360×800、844×390及1024→1025边界连续resize。

每种布局保存初始地图、默认选点、收起、专注、恢复的真实截图，量出工作区、案、正文、安全区矩形；默认地图预算为硬出口。标题／正文无截断、无横滚；收起态隐藏正文不入Tab，地图没有假可点击点；专注恢复、退出、快速改选不残留隐藏样式。

检验地图拖缩时读案不抢滚轮，正文滚动不带动地图；短诗、长文能读完，篇目焦点与记忆、目录搜索对应作品、出处最上层、全国／局部／关闭恢复仍正确。静观与减少动态路径可用，动画只服务状态变化，不添加自动漂浮和纸纹动画。

版式截图、模拟鼠标／触控与实体手机证据分别记录；前两者不能充作实机双指验证。全国栅格边线／嵌入城市注记质量另列，不能因为缩窄读案便宣布官方PNG美术全部完成。
