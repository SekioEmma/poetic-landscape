# 第十轮：柔和界面与地图交互规范

2026-10-07；与总计划v2.9配套。用于本轮实现与验收，明确覆盖旧规范中被执行成“全站直角”的部分。参数为本项目决定，参考产品不是尺寸抄本。

## 1. 设计目标与保留项

目标是“地图上一页温润的读笺”：地图是连续背景，阅读、搜索与工具浮在合适位置，操作状态明晰；纸墨、细笔画与诗句负责文化气质。赵佶研究方向继续落实为细察物象、薄层设色、疏密与清雅，不把古雅等同于直角，也不把现代流畅等同于玻璃特效。

保留原文、篇目／地点两视图、作品级雪夜／春行画、6／8／8数据、图源披露、全国PNG＋Panzoom和局部L7／MapLibre。诗文不进内层卡片网格，画不加相框、不占原文首屏。

## 2. 界面形态与材料

| 元素 | 本轮初始参数 | 处理原则 |
|---|---|---|
| 桌面／平板读案外壳 | 圆角24px，右20px／底12px沿用；平板最大宽630px | 一层洁纸面；细微环境阴影，不描四边实线 |
| 手机底案 | 四角24px；左右12px；底部max(12px,安全区+8px) | 能见两侧地图；不能为了圆角增大高度挤地图 |
| 手机专注 | 左右8–12px，圆角24px；高约工作区94% | 明确主动展开；可回常态，仍保留地点与进度 |
| 收起案 | 圆角20px，桌面宽280px；手机宽calc(100%-24px) | 地名、当前篇名、继续／关闭；长名可两行，不截断 |
| 搜索入口 | 桌面约260–300×44px；手机44px高、约96–120px宽；圆角22px | 复用原导航位置，不另添一条永久大工具栏 |
| 搜索目录 | 外壳22px；桌面宽360–380px；手机左右12px | 单一滚动结果区，固定搜索及筛选；正文结果不每条描框 |
| 篇目浮层 | 圆角14–16px；内距8px；选项min-height52px | 篇名全显示、作者另行；当前标记＋轻底色，避免条条卡框 |
| 缩放组 | 44px宽×88px高、圆角16px；独立复位按钮44px | 明确可点，按钮边界靠留白与反馈，不铺长文字条 |
| 来源／原图弹窗 | 外壳20px，照片显示处12px | 可滚、可关闭、焦点可见；图片等比例且原署名完整 |

纸色#F4F0E6，读纸#FCFAF4，浓墨#2E3430，次墨#60685E，青绿#506553，朱#8D5044。初始阴影参考`0 8px 28px rgba(46,52,48,.08)`，可再加极淡纸缘；不加明显灰四边框，不做磨损／锯齿边，不给每层重复阴影。圆角只用于可操作容器，不给诗段、篇名、图题或每条结果套胶囊。

正文18px保留；地名20–22px、篇名23–26px；工具14px、说明至少13px。轻墨不能替代对比度；按钮反馈用浅青纸底，当前关键状态用朱小标，朱色不满屏。

## 3. 布局：地图与主要信息面板

沿用`measureReaderLayout`一个协议与实际header测量。设T=视口高−headerBottom−8−底边距；底边距须包含实际安全区。

| 状态 | 显示与尺寸 | 地图原则 |
|---|---|---|
| 探索 | 地点案关闭；地图、搜索入口、工具 | 全图可操作 |
| 常态side | 沿用宽320–420px；工具合入地名行，标签在下一行 | 可用地图宽≥视口55%；手机横屏≥50% |
| 常态bottom | 高约0.48T，上限不突破地图≥0.50T预算 | 上方地图可拖、缩放、换点；不锁死页面 |
| 收起 | 目标104–120px，可为长名增长但须记录 | 保留当前点、作品、两类地图与阅读位置 |
| 专注 | side宽560–620以内；bottom约0.94T | 由明确操作进入；不假称地图主导常态 |
| 搜索目录 | 打开时暂时隐藏读案，保留所有阅读状态；桌面左侧，手机在工作区内 | 避免左右两个大面板同时夹地图；目录关闭可恢复原案 |

读案固定区改为“地名＋三个紧凑操作”一行、“诗文／地点＋篇目”一行。手机再加grabber占20px左右，总固定区目标108px以内，360窄屏长地名可放宽至116px但须实际记录。常态正文目标≥220px（390×844、360×800）；短横屏允许收起默认与196px左右可滚正文。不能减18px字号凑高度。

手机grabber视觉36×4px，热区至少44px宽；可与地名行共用部分垂直热区以控制固定区高度。拖动只在grabber／非按钮标题空处起手，不在全文、链接、篇目选择上抢手势。标题、工具不会遮盖正文；发生两行标题时真实测量，不写死假高度。

## 4. 控件与地图工具位置

全国与局部共用一套工具外壳，各调用既有引擎。缩放组放在**可见地图安全矩形右下**：x=安全区right−44−12；y=安全区bottom−88−12；复位按钮在其上方，间隔8px。位置按实际矩形计算，不能用全视口固定bottom让按钮躲进读案；若小屏地图工具与当前题注重叠，优先挪工具至安全区右上，不挪地理锚点。全组不得压在标注热区上。

全国复位名“看全国”；局部名“定位此地”，保持真实语义。局部“回全国”作为地图可见左上44px高小胶囊，地点正文入口仍可保留为辅助；不能必须打开地点并滚动才能回全国。全国原图对照移至统一来源入口的原图按钮，点击最多两步可达；地图来源与原件说明始终可查。

按钮至少44×44，hover／press／focus-visible各有可见反馈；图标用现有线条SVG体系，提供title与aria-label，不能用emoji或只有不可发现的裸线。键盘焦点不能为消除矩形感被删除；滚动正文focus样式与纸面一致，避免常驻装饰边框。

## 5. 操作状态与返回语义

| 触发 | 状态变化 | 必须保留／更新 |
|---|---|---|
| 点地图另一地点 | 打开该地点常态案；低高横屏按默认收起 | 当前作品为该地点默认／搜索命中篇；镜头只按遮挡需要修正 |
| 常态“收起” | reading→collapsed | 地点、篇、tab、语义位置、用户镜头 |
| “展开阅读”／“恢复大小” | reading↔focused | 同一篇同一阅读锚点；不回卷首 |
| “继续阅读” | collapsed→reading | 恢复本篇、本视图进度 |
| 关闭×或品牌首页 | 任意读案→探索 | 使用既有探索视野恢复；终止旧动画；关闭后快捷键不能驱动隐藏案 |
| 打开搜索 | 保存案快照→案暂隐→目录 | 镜头／阅读不因目录出现而重置 |
| 关闭目录／目录Esc | 目录消失，恢复打开前案与焦点 | 搜索输入／主题按原规则保留；零结果当前读文不丢失 |
| 点结果 | 目录关闭→该点常态案 | 作者／篇名命中时打开命中篇；新选择优先于旧退出回调 |
| 点选篇 | 只换正文；选择列表关闭 | 地点与镜头不变；新篇初读从头、回旧篇恢复 |
| 点空白地图 | 保留当前案；允许探索地图 | 不擅自关闭或复位；拖动后抑制误点 |
| Esc | 依次只关最上层：来源/原图→篇目浮层→目录→读案 | 延续既有读案Esc关闭合同；不在本轮偷偷改为专注退一级 |

“收起”不等于“关闭”，“回全国”不等于“回首页”。全站统一词汇，`恢复分屏`改为`恢复大小`。未引入页面路由时不人为劫持系统浏览器返回。

手机面板三档为collapsed、reading、focused。手指向上表示查看更多，向下表示让出地图；超过48px且释放速度低时选最近档，速度绝对值超过0.45px/ms时朝速度方向进相邻档；参数只在实际评估后小幅调整。最底档再下拖不销毁阅读，只保持收起，明确×负责关闭。拖动<8px当点击，不误切档；pointercancel／旋转时取消拖动并落回有效档。grabber支持键盘Enter循环档位、上下键相邻档位，并有“调整阅读案高度”标签。

本轮不将正文滚到顶的下拉映射为收案；全文原生滚动、文本选择与链接优先。地图滚轮仅作用于地图，正文滚轮仅作用于正文。实体设备未测时不得宣称双指／手势验收通过。

## 6. 动效与证据

| 变化 | 初始动效参数 | 判断标准 |
|---|---|---|
| 按下／选中反馈 | 80–120ms，浅底或墨色变化 | 首次反馈≤100ms；无需等退出结束才能点下一项 |
| 读案进入／收起／恢复 | 240–280ms，`cubic-bezier(.2,.8,.2,1)` | 位置及外壳尺寸／裁切连续，标题不瞬移；正文不scale |
| 专注↔常态 | 260ms上下，宽度或裁切连续 | 不允许先换到终态width再仅横移，内容清楚可读 |
| 篇目／内容切换 | 80–140ms可选淡入，外壳稳定 | 不跳镜头、不把整案再次飞入 |
| 手动拖案 | 手势跟随；释放180–260ms停靠 | 可中途反向、第二次操作接管；没有甩动循环 |
| 减少动态／静观 | 去位移和弹性，0–80ms透明度或即时 | 输入与恢复照常成立；停止一切装饰循环 |

从当前呈现矩形接续下一次变化，不跳回动画原起点。读取位置在稳定态按语义锚点恢复；不缓存会被旧timer覆盖的新选择。地图相机只在必要时修正到最终安全区，不为每一动画帧fit；用户拖地图立即接管，不被面板停靠重新抢镜头。相机、面板和焦点必须使用同一状态来源。

至少提供一次常态→专注→常态的0／中段／终态矩形记录，证明尺寸／裁切在中途变化；一次100ms内反向和退出中选新点的记录；另录简短交互屏幕片段或等时间真实截图序列。只有终态截图与CSS时长不构成“丝滑”证据，不虚写60fps。
