# 全国地图标签与聚合规范 v1

2026-10-09。适用第十四轮，当前正式9点、未来12点及隔离40点。覆盖此前标签底色、整体44px移位和聚合点击直接fit到最高合适倍数的做法；保留其他地图／阅读／美学规范。

## 1. 成熟方案研究：机制与本项目提案分开

本次研究官方SDK文档和代码示例，未登录或全面实测Google／Apple消费端。不能把本项目参数称为其官方UI参数，也不能把SDK示例直接描述为消费端内部实现。

| 原始方案／可核出处 | 原方案机制 | 本项目采用方向 |
|---|---|---|
| [Google Advanced Markers碰撞](https://developers.google.com/maps/documentation/javascript/advanced-markers/collision-behavior) | 区分必须显示与可让位标注；优先级影响重叠时显隐，矢量底图可与底图标注协调 | 当前选中／键盘焦点优先，普通地名和省名让位；不要只调z-index把两个名字叠住 |
| [Google聚合示例](https://developers.google.com/maps/documentation/javascript/marker-clustering) | 附近点聚合，随缩放合并／分解，数字表示成员数 | 同一成员不能重复计数，聚合视觉与个体视觉清楚不同，隐藏文字仍保留入口 |
| [Apple MapKit聚合](https://developer.apple.com/documentation/mapkit/decluttering-a-map-with-mapkit-annotation-clustering)、[displayPriority](https://developer.apple.com/documentation/mapkit/mkannotationview/displaypriority)、[clusteringIdentifier](https://developer.apple.com/documentation/mapkit/mkannotationview/clusteringidentifier) | 碰撞与共享聚合标识形成分组，displayPriority决定标注显示优先 | 借“分组资格＋显示优先级”的区分；不能把地理邻近强行解释成同城。Apple正文页面依赖JS，本次以官方检索摘要核机制，不称全面实测原生示例 |
| [Mapbox标注排布](https://docs.mapbox.com/help/dive-deeper/optimize-map-label-placement/) | 多候选位置、原位置优先复用、层次与排序影响显示 | 当前已试6候选，下一步增加稳定身份与上一位置缓存；普通点优先换文字位置，保持地理点不动 |
| [MapLibre原生聚合示例](https://maplibre.org/maplibre-gl-js/docs/examples/create-and-style-clusters/) | 点击cluster可查询 `getClusterExpansionZoom` 后展开 | 使用当前锁定引擎公开API找下一分解尺度，结合本项目自动缩放上限与安全区 |
| [MapLibre symbol规范](https://maplibre.org/maplibre-style-spec/layers/#text-variable-anchor) | 支持text-variable-anchor、symbol-sort-key等 | 是备选渲染路线；本轮可保留DOM交互标注，不能仅抄属性名就声称原生symbol已实施 |

保留现有L7／MapLibre，不接入Google或Apple服务，不新增Key、底图授权依赖或地图引擎。推荐先将现有DOM排布整理成稳定的测量／排布模块；9–40点无需重造地图渲染器。若试原生symbol，先核锁定版本API、中文glyph与字体资源、本地加载和键盘可达，证据成立才迁移，不能临时联网拉字体使离线交付失效。

## 2. 图面信息层级

从高到低：当前阅读地点／键盘焦点 → 搜索匹配 → 地点／聚合入口 → 普通文字 → 省名 → 地理底线。焦点高亮可临时超过普通文字预算；移走焦点后恢复原有布局。搜索多个结果不都视为必须显示，用相同稳定排序。

图标与数字不是相同含义：个体用现有文化类别图；聚合用清楚的计数符号，数字只算地点，不算作品。作品数量在名单显示。单点不能显示“1”的假聚合。

全国保持东西部文化入口，按屏幕密度自然聚合；区域分解后完整地名有优先权；高倍只有省界时允许留空，不编造道路、山水或遗址平面。没有名字的点仍可点／键盘聚焦，并在聚焦或名单提供完整名称。

## 3. 锚点、文字与安全区

- 真实经纬度、转换及源几何不变。正常图标固定在真实锚点，不再仅因相距小于44px就把它移到44px外。
- 先尝试文字右／左／上／下／对角候选；上一合法候选优先复用。缓存使用placeId或排序后的成员ID集合，不使用会随worker重建改变的cluster_id作长期身份。
- 真重合或触区无法可靠区分时用聚合／近邻名单。确需临时展开同坐标点时保留真锚点和短引线，只用于明确展开态，退出即恢复；不永久平移建筑位置。
- 安全区包含页头、读案、工具、出处署名、近邻名单及测试说明。文字也不能盖另一文化图标；省名给文化标注让位。
- 名称宽度使用真实字体测量，包含长题名与字号；普通名字不得以改坐标或缩到12px解决重叠。空间不足可只显示图标／数量并保留完整aria名称。

## 4. 聚合点击与镜头

**一次点击推进一个可理解的层次，不一次把全国飞到遗址尺度。** 提案参数不是Google／Apple官方要求：普通聚合一次自动放大最多约2级，自动定位不改变11.5手动探索上限。

有真实下一分解级时采用该级并结合可用图面的边距；分解需要超出单次预算或成员极近时，展示可关闭的成员名单，不能让同一组点击无反馈，也不能自动连飞多次。可保留明确“展开地图”动作继续探索，不能用计时器自动接着飞。

低倍西北组应该先进入能理解西北分布的区域：看到楼兰与敦煌组，再处理玉门关／阳关。候选镜头预留桌面约64px、手机约40px内部安全边距，并计入文字大小；不是把点贴着屏幕两端“只要没出界就算过”。边距遇小屏不足时先选名单。

点击个体仍进入原文，选中点在读案外；切作品不改变相机。手动拖缩立即接管，不被聚合异步回调、名单打开或安全区修正抢回。明确看全国始终完整复位，不能用9点bbox代替全国地理范围。

## 5. 标签视觉

沿用墨、纸、薄青及少量朱色。普通地名以16px宋体墨字为基线；组名可14–16px、数字13–14px，具体以实际图面辨识为准。44px触区不意味着画44px大圈。

普通文字优先无硬矩形底色，必要时用轻微纸色护字或极薄柔和底；默认不加统一阴影、边框、长纸条。选中与焦点可加强朱色／笔线及短底，避免叠加圆底、粗线、下划线和外框。聚合数字保留紧凑辨识，不能每组都展开长区域全称撑成同款卡片。

近邻名单是唯一需要完整容器的地图浮层；沿用轻纸面14px软边，完整地名、区域、篇数、44px关闭和明确选中状态。名单放在可用区并避工具，短屏可滚，不引入第二套地点详情。

“甘肃与新疆”可按真实成员使用有定义的“西北”，完整区域在名单呈现；跨省非同区的泛数量组保留数字，也可以用真实省份短名，不能硬称敦煌。所有命名规则集中配置并测试，不随截图手改九个地名。

## 6. 稳定、动效与可达性

地图移动中不批量删文化点。现有标注跟随地图，成员重建在合适的引擎事件后发生；省名可退场，文化文字仅在确有碰撞时让位。停稳后一次排布，避免每次微小缩放都换文字左右。

成员不变、镜头回到原值时优先恢复同一候选位置。显隐可采用约100–160ms轻淡入，尊重减弱动画；不做每个地名飞入、弹跳和错位追逐。不宣称未测的60fps。

聚合／个体保持button语义，Enter或Space等价点击，焦点有可见名称；名单Esc关闭，焦点回有效触发入口，触发点已消失则回地图或合理下一入口。避免重写整个innerHTML导致焦点、文本测量和动效状态丢失。列表不必锁住地图全部操作，但不能键盘穿透到被读案／目录遮挡的控件。

## 7. 验收出口

正式9点及隔离12／40点使用同规则；三尺寸核对全国、区域、近邻、读案外四种上下文。测可见成员集合、文字碰撞、锚点与安全区、重复来回的候选位置、聚合点击幅度与最后一次操作。仅统计“显示标签数”或截图不相交不足以证明入口完整。
