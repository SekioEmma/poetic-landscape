2026-10-08。适用于第十二轮及之后的地图、读案、搜索与工具。**产品组织以用户指定的Anthropic／Claude简洁、优雅、直观为主要参考；艺术语言以赵佶相关作品及《宣和画谱》为主轴。** 地图仍是主界面，原文是阅读主内容。

### 1.2 《宣和画谱》：不是古代组件库

[国立故宫版本说明](https://theme.npm.edu.tw/selection/Article.aspx?sNo=04001073)介绍其为徽宗内府藏画谱录，1120年成书，二十卷、十门；所藏元大德六年刊本具有重要版本价值。作者不详，不能简单称赵佶个人亲撰的设计手册。十门分类不直接替换地图主题筛选。

重点核读两个篇章：

| 原文依据 | 可支持的理解 | 具体落实 | 边界 |
|---|---|---|---|
| [卷十《山水叙论》](https://www.shidianguji.com/zh/book/SK1644/chapter/1jurp1afq08c2)：谈咫尺容纳远景，并指出有笔法却“多失位置” | 技法细腻不能补偿构图失当，整体安排和局部细节都要成立 | 全国适配、安全区、地名和读案的相对位置先定；不能地图挤成窄缝后用漂亮插画补救 | 这是设计类比，不把真实地理投影改成山水画透视 |
| [卷十五《花鸟叙论》](https://www.shidianguji.com/zh/book/SK1644/chapter/1jurp1dtgk2zq)：强调“与诗人相表里”，区分物象情态，又批评只有工巧而缺韵 | 物象和诗意应互相解释；技法、颜色和精细度不是唯一标准 | 插画选主物象前先写关联诗句；雪亭、春湖、暮钟、关山分别有季节／时辰／情绪，不用同一张鸟花填所有地点 | 不把每个条目硬套帝王祥瑞／富贵寓意，不把文本赞誉当客观评分 |

电子文本是选段阅读入口，正式论文引用应对照影印本核字与页码。[中国哲学书电子化计划的四库本影印入口](https://ctext.org/library.pl?if=en&res=6141)标示来源浙江大学图书馆、CADAL，分四册。此次核对入口，未完成逐页校勘；不采用机器译文代替原文依据。

## 2. 本项目的统一设计命题

**像使用成熟阅读工具一样直观，像观看一幅精整的宋画册页一样安静、细致。** 全国图是主画幅，文化地点是锚点，读案是旁侧展开的作品页；控件属于可用工具，意境来自与诗文相应的构图和物象。

宋代尤其徽宗朝艺术不只有简淡一路；本项目选择其清雅、精整、书画相应的一面，兼顾用户的柔和质朴要求。纸感为屏幕阅读而设计；参考绘画多为绢本，不能写成“赵佶宣纸风格复原”。默认小景已有两幅，本轮优先组织现有资产，不增加全套插画。

## 3. 设计令牌及组件边界

沿用当前六个基础色，不整站改色；水色和纸界沿用现有派生角色。以下是实现试验起点，依据真实页面修订，不是历史颜料还原。

| 角色 | 值 | 用法 |
|---|---|---|
| 素纸 | #F4F0E6 | 全国画布及底层工具环境 |
| 洁纸 | #FCFAF4 | 一层阅读面、搜索展开层 |
| 浓墨 | #2E3430 | 原文、当前篇名、重要操作 |
| 淡墨 | #60685E | 作者／地区／辅助说明；不得再降低小字对比 |
| 青墨 | #506553 | 地名、链接、焦点与正常操作 |
| 朱墨 | #8D5044 | 当前文化点或选中短线，不用于所有按钮／全部地图点 |

### 字体与密度

- 原文18px以上，正文说明16px左右；辅助地区／作者14px左右，出处细节最低12px且仍可读。诗行行高先试1.85–2.0，段间距按文体调整，避免每两行就空一个大块。已接受原文结构优先保持。
- 站名24–30px、地点标题24–28px、作品标题22–28px，手机按实际宽度缩减；不同时放三个大标题。标题／原文宋体，工具用清晰系统无衬线，两套角色足够。
- 地图独立地名14–16px，省名12–13px，使用浓淡和内容优先级区分；不将地图题注做成大书法字卡。
- 瘦金体只在授权与字符覆盖落实后用于站名／少量题签，保持宋体回退；不用于正文、地图小字和交互控件。正文不因审美目标变成细淡、无法复制的图片。
- 正文左对齐，诗文按文体组织；地图／选点定位不为文字排版挪真实坐标。字距克制，不全站扩大字距模拟古意。

### 边缘与容器

| 元素 | 起始规则 | 减轻框感的关键 |
|---|---|---|
| 读案外壳 | 18–24px软边，手机依空间可更柔；一层背景和极轻分离阴影 | 只有外壳承担面，不在里面再套同底卡；正文内部开阔排布 |
| 搜索展开层／近点名单 | 12–16px，轻纸界；与触发入口同一对齐轴 | 工具职责清楚，列表用行距／文字层级，禁止每条独立厚卡 |
| 地图工具 | 44px触区，图形20px左右；定位可独立圆形，＋／−为一组 | 使用成熟工具形态，减轻阴影，禁用可见，不给每个按钮画印章 |
| 诗文／地点标签、篇目条目 | 文字＋单个选中短线或浅面 | 不把每种选中方式叠在一起，不全部胶囊化 |
| 原文、解读、底本段落 | 默认无外边框；只在信息改变时用细分隔 | 通过字体、间距、对齐表现层级；不是统一0px圆角的报纸模板 |

纸纹仅在底层轻微可感，正文最洁；当前opacity值只是资产实现值，不能作为纸感达标指标。在100%观看时，若斜划痕／噪点／重复瓦片先被看到则减弱或替换。没有交互的纹理全部透传。禁止假破边、烧黄、泛灰雾或整幅名画壁纸。

## 4. 全国地图与读案的统一五态

| 状态 | 主对象与可见信息 | 主操作及返回逻辑 |
|---|---|---|
| 全国探索 | 完整全国形状、少量文化点／区域分组；站名与一个搜索入口 | 自由拖缩／选点；看全国主动复位。首页题诗只留一处，首次探索后简化 |
| 地点常态 | 地图仍主导，选中点清楚；旁侧读案给地点、篇目、原文 | 读原文与切篇；地图外区域仍自由探索。关案恢复进入前探索镜头 |
| 收起 | 保留地图、选中点和紧凑题签 | 继续阅读恢复同篇、同位置；不重飞、不丢手动镜头 |
| 专注阅读 | 原文／画作／说明按顺序，集中观看 | 主动回到常态；隐藏图控件不进入Tab，不自动进入专注 |
| 搜索结果 | 搜索输入和实际结果；地图同步同一集合 | 选择结果进入阅读，清空恢复；空结果提供改词／清空，不重置用户镜头 |

桌面常态地图宽至少55%，读案先试360–420px；手机竖屏常态地图高至少工作区50%，收起题签约72–96px。这些约束来自项目空间协议，不属于Anthropic像素规范。1000／1024／1025边界实测，动态地图安全区统一计算。

全国矢量精确、国界清楚、省界退后，文化点比行政注记优先；低倍看整体、高倍看锚点。留白须服务观看方向或题款位置，不能把大面积没有内容的空洞叫宋代气韵。扩大zoom不是增加道路数据，不虚构建筑细节。

地图分组呈数量及可靠区域线索；文化地名不遮主锚点；选中图标、地名、朱色强调只构成一套状态。省名按当前可见范围排序，临界尺度使用迟滞，不因每一帧重算产生跳字。真实坐标／边界不改变，绘画只在明确意境区域出现。

## 5. 图、诗、资料的关系

原文始终优先，画作不占手机首屏大半高度。切换作品同时更新该作品题名、作者、原文、高亮、解读和既有作品级意境图；地点／原相机不变。画与相关文字相邻，底本按需展开，不与主原文同视觉权重。

每幅画有一段内部说明：对应哪篇、哪句、季节／时辰、主物象、为何安排密部和空处。雪景／春景不机械通用。地名按钮图标仅负责识别，不能要求44px图标表现整幅宋画。

今日照片保持真实与许可信息；意境插画明确其身份；地理图表达真实空间。不得以艺术改造混淆古址复原、今天实景或历史路线。本轮无需重新画已有两画；若有具体不合诗意的资产缺陷，单项说明后修整。

## 6. 交互与动效

- 原生连续拖缩优先于任何美术动效。停止旧自动定位，不停止原生处理器；不能因“安静”把滚轮禁用。
- 状态反馈立即发生；工具反馈120–180ms，读案外壳180–240ms，明确定位240–320ms为试验起点，允许随设备减弱。原生地图运动不叠CSS transition。
- 展开／收起沿同一空间关系；专注强调阅读范围变化，不制造整页翻书。快速操作可打断，最后意图胜出，不让旧timer回跳。
- ＋／−的连按累计目标；看全国、收起、关闭名称和结果一致。触点44px左右；缺图、无结果、失败都写实际状态和下一步动作。
- 主动输入后的省名／辅助标签可在稳定后补齐，但选中点、操作工具不能消失。内容稳定阅读，不逐字动画、循环花瓣、飞鹤、纸面波纹。
- 键盘、焦点与系统减弱动画单独验证；模拟viewport不是实机触摸证据。
