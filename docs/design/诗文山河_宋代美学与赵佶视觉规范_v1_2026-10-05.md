# 诗文山河：宋代美学与赵佶视觉规范 v1

**用途**：指导“诗文山河”中国地图首页、地点标记、诗文阅读案、局部地图及主题卷的前端设计与验收。此文是设计转译规范，不主张复原北宋原作或历史建筑。2026-10-05 基于馆藏、艺术史研究与项目现状编制。

## 一、总方向：精微、清润、有秩序的诗画同观

在“宋代美学”大范围内，主轴选 **赵佶与宣和画院的花鸟、题诗及书画陈设方式**，辅以北宋山水画的空间层次。不要把“宋代”泛化成米黄背景、茶具、卷轴边和密集印章，也不要把北宋院画等同于后世文人写意画。故宫称赵佶主持画院，要求对物象细察，并以诗意丰富画面；大都会博物馆也将其时代的宫廷绘画描述为重视自然观察、诗意与古意的结合。[故宫《芙蓉锦鸡图》馆藏说明](https://www.dpm.org.cn/collection/paint/230125.html)、[大都会博物馆·北宋绘画](https://www.metmuseum.org/pt/essays/northern-song-dynasty-960-1127)。

**一句视觉命题**：把可探索的中国地图当作一幅有地理依据的山河图；地点是精绘的小景，诗文与题注在旁相互照应。画面安静，但观察细、层次足、触点清楚。

设计时遵循 [Anthropic 的 frontend-design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)：先由真实题材与内容定色彩、字体、布局及交互，再检查是否落入通用模板；实现后用桌面和手机截图自评。它是工作方法，本文件才是本项目的具体视觉依据。现有 [MVP 开发计划](../诗文山河_MVP开发计划_2026-10-05.md) 和 [设计令牌](design-tokens.json) 仍是产品与工程边界；此文件细化美术规则。

## 二、参考作品与转译边界

| 作品／著作 | 已核实的可取之处 | 在界面中的转译 | 不照搬的部分 |
| --- | --- | --- | --- |
| [《芙蓉锦鸡图》](https://www.dpm.org.cn/collection/paint/230125.html)，故宫 | 绢本设色；双钩细线、鸟与花的动态、淡浓层次、画与题诗相映；故宫分析其可能为画院画家绘制、赵佶题诗 | 地点小景以 1 个细察的主物象为中心，文字落在留出的空处；线条精确，设色有限 | 不宣称此画必由赵佶亲绘；不把锦鸡、芙蓉复制成全站通用图标 |
| [《听琴图》](https://www.dpm.org.cn/collection/paint/231409.html)，故宫 | 雅集人物、松竹与器具在简净背景中建立主次；馆方正文指出画院作者的考证 | 阅读案先给一处视觉焦点，其余信息按节奏展开；“此地”插画以人物／建筑比例衬出山河 | 不把画中人物、器具当作所有诗文时期的通用服饰和道具 |
| [《瑞鹤图》](https://zhuanti.mct.gov.cn/lnsbwg2022/detail/7362.html)，辽宁省博物馆馆藏资料 | 绢本设色，以建筑屋脊与天空中的鹤形成下密上疏的空间关系 | 首页可用极轻的上空留白和下缘山川层次；重点地点小景有“密部”，地图其他处保持安静 | 不做满屏飞鹤、祥云或祥瑞特效 |
| [《竹禽图》／*Finches and Bamboo*](https://www.metmuseum.org/art/collection/search/39936)，大都会博物馆 | 精察禽鸟和竹的姿态，画面虽小而有生气；馆藏标记为 public domain | 细节只用于选中地点的局部图，不把所有标记都画成复杂图案 | 不把馆藏图像直接裁成按钮；若真正使用其数字图像，仍记录馆方来源与使用条件 |
| [瘦金书](https://www.dpm.org.cn/lemmas/240221.html)，故宫 | 瘦细、挺劲、结体疏朗且有锋芒 | 仅用于题签气质：少量细长的结构线、疏朗字距、轻而明确的标题层次 | 不以普通宋体冒充赵佶手书；不拿未经授权的“瘦金体字库”做正文 |
| [《宣和画谱》](https://www.dpm.org.cn/lemmas/243202.html)，故宫 | 宣和年间官方主持编撰，按画科著录、重物象情态与格调 | 内容分类按地貌／建筑／诗文关系组织；作品来源与说明是画卷的“题注” | 不称作赵佶个人亲撰，也不把古籍的分类硬套在地图主题上 |
| 郭熙《林泉高致》及“三远”讨论，[人大哲学院研究](https://phi.ruc.edu.cn/xsyj/sxwk/97dbe5c8c548441aaa43f48b18cd990a.htm) | 高远、深远、平远是观察和安排山水的理论 | 全国图为平远总览；打开地点以局部地形和前中后景逐层进入 | 这是界面设计类比，不声称交互地图等同于宋画透视 |

进一步研究可查 [浙江大学《宋画全集》项目介绍](https://rwsk.zju.edu.cn/2010/0408/c2039a170355/page.htm)及[清华大学图书馆《宋画全集》目录](https://lib.tsinghua.edu.cn/arts/info/1021/1141_5.htm)。赵佶与宫廷收藏的研究，以[故宫刊载伊沛霞《宫廷收藏对宫廷绘画的影响：宋徽宗的个案研究》](https://www.dpm.org.cn/paints/talk/208746.html)、Patricia Buckley Ebrey 的 [*Accumulating Culture*](https://uwapress.uw.edu/book/9780295987781/accumulating-culture/) 为后续书目入口；本轮核实了书目信息和公开摘要，未声称通读专著全文。

**材质界限**：上述赵佶相关绘画多标为“绢本设色”。项目中的宣纸感是屏幕界面为了柔和阅读而做的当代设计选择，不是其作品底材的复刻。长卷体验可参考[大都会博物馆对手卷逐段展开的介绍](https://www.metmuseum.org/ja/essays/chinese-handscrolls)，但全国地图必须保留自然的缩放与拖动，不用卷轴动画替代地图交互。

## 三、可直接实现的设计令牌

色值沿用既有方案，以**层次使用**代替整体换色。下列强度、比例均是屏幕设计建议，不是宋代颜料的数字复原。

| 角色 | 色值 | 使用范围 |
| --- | --- | --- |
| 素纸 | `#F4F0E6` | 地图外画布、浅底 |
| 洁纸 | `#FCFAF4` | 阅读案正文背景 |
| 浓墨 | `#2E3430` | 标题、原文、关键地名 |
| 淡墨 | `#60685E` | 正文说明、元信息 |
| 石青绿 | `#506553` | 选中地点、链接、焦点状态 |
| 水色 | `#A8BBB9` | 水域和淡线，不能用作小字色 |
| 朱砂意象 | `#8D5044` | 题签与少量状态强调，每屏不超过 2 处主强调 |
| 纸界 | `#D7D6CB` | 纤细分隔，不围满组件 |

- **面积**：地图和底色占视觉主体。桌面首页文字、按钮、小景等非地图层覆盖的面积控制在视口约 30% 内；详情展开时不遮住被选地点。这里的比例用于截图检查，不作 CSS 硬裁切。
- **色彩比例**：近白与浅纸约 75%–85%，墨色约 10%–20%，青绿与朱色合计不超过约 8%。朱色只作为印记、选中线或局部提示。
- **纸纹**：以原创静态细纤维与微小色差制作 256px 可重复纹理，地图层实际混合效果应非常轻，正文阅读区更淡。现有 CSS 的 `.paper-fibres` 使用 `opacity:.34`；这是纹理层的不透明度，不等于人眼感知的纸纹强度。验收时以截图和阅读性评估，若纹理在普通缩放下先于文字被注意到，就继续降低。不得给文字叠加噪点、滤镜或斑驳缺字效果。
- **边线**：地图真实海陆边界不改形；内容分隔线 1px、低对比、可不连续。不要一张卡一圈边，尤其不要通过模糊阴影表达“古意”。
- **触感**：温润来自微弱肌理、线的轻重和周围的空处，不来自大圆角。默认组件不设统一圆角；照片可以有极细的浅边，不加相纸磨损框。

## 四、字体、题跋与图文关系

1. **主阅读文字**：沿用项目已规划的思源宋体／系统宋体回退，正文 16px、行高 1.7–1.9；诗文原文 18px、行高约 1.9。交互标签可用清晰的系统无衬线。正文颜色只用浓墨或淡墨，按现有设计令牌保持可读对比。
2. **瘦金体展示字**：根据用户最新选择，站名“诗文山河”、地点详情标题及精选短诗句优先采用有明确授权的瘦金体字库。桌面站名 40–48px、地点标题 30–36px、短诗句 24–28px；手机分别约 30–34px、28–32px、22–24px。使用字体原有常规字重，不伪加粗、不拉伸、不添加阴影；字距从 0.03–0.08em 试起，按实际字形调整。小字号地图地名、长篇原文、说明与按钮保持清晰的宋体或系统字体。题签文字是实际标题或地名，不堆“第一卷／第几章”等装饰元数据。

   **字库候选**：[方正瘦金书官方产品页](https://www.foundertype.com/index.php/FontInfo/ductdetail/id/150.html)提供简体及简繁版本，并列出发布与嵌入式应用等不同授权；[官方云字库接入页](https://shop.foundertype.com/index.php/CloudAuth/useFont/id/FZSJSJW/font_name/%E6%96%B9%E6%AD%A3%E7%98%A6%E9%87%91%E4%B9%A6%E7%AE%80%E4%BD%93.html)提供 Web 字体接入说明。选型时确认网页使用方式及所需字符覆盖，授权和文件落实前保留宋体回退。展示字体是对赵佶书风的数字化设计，不标作赵佶亲笔。
3. **诗画同观**：一处地点的视觉顺序是“地名 → 一句关联诗文 → 诗题作者 → 小景／今日图景 → 解读和来源”。图不单独占满整屏；题注与画面保持相邻，不能远隔到另一页才解释。
4. **竖排范围**：桌面只有 1 句不超过 20 字的引句可以竖排；全文、来源、说明和手机界面均横排。竖排不可成为影响复制、检索或朗读的唯一文本呈现。
5. **印章**：整屏最多 1 个小型印记。只有确有信息含义（站名、所选地点、主题）才使用，不在每张卡片右下角重复盖章。印记由项目原创制作，禁止把历史收藏印裁成通用装饰。

## 五、空间构图与地图页面

### 首页：山河是主角

中国地图必须是第一眼的主体。标题放在地图之外的留白或稀疏区域，不能盖住密集地名。全国视野采用“平远”般的宽阔横向阅读，水系和地形只作很浅的辅助。点位覆盖多时先分层或聚合；不能为追求画面疏朗而移动真实坐标。

首页最多安排 **一幅原创小景**：例如一枝、半亭、孤舟或关城局部。小景要符合当前主题，淡设色且面积控制在桌面视口约 12% 内。全国地图上的每个地点只显示清楚的名称、类别或状态；选中后再出现更精细的插画或诗句。装饰不得假装地图地貌、行政边界或历史路线。

### 地点详情：小景与题诗互相照应

阅读案仍是纸张，但不像一张直角卡片贴在地图上。使用一段短细边线、顶部留空与轻微底色差建立层级；压低背景纹理，保证原文是最清楚的一层。标题区域聚焦一个地名和一句诗，不同时放多个主视觉。作品切换仍可用文字标签，但不要把每篇诗做成同尺寸卡片网格。

“此地”页将局部地图、今日照片、原创宋画式小景明确区分。今日照片保持真实色彩和来源；原创小景标“意境插画”，不要暗示是古代原址复原。地图先传达地点与江、山、城、关之间的空间关系，插画再传达诗意。

### 主题卷：按阅读节奏展卷

卷的推进可以“总览 → 一处聚焦 → 继续下一处”，每次只让一个地方成为视觉主角。这是受手卷逐段观看启发的交互节奏，不做夸张的卷轴打开、书页翻转或自动巡游。用户随时可返回中国地图。

## 六、笔线、插画与动效

**线**：小景以准确轮廓和少量内线表现建筑、鸟、竹、石、舟。桌面主轮廓约 1.2–1.6px，局部精细线约 0.8–1.2px；在实际尺寸和高倍屏上查看，过细或消失时加粗。允许线条有轻微粗细变化，但不使用随机抖动伪装手绘。

**设色**：每张小景优先 1 个墨色主调、1 个青绿或水色辅调、极少朱色重点。花鸟可较山水精细，但一张图中的精绘区域集中在一角或一个对象；其余区域留空。赵佶相关题材可参考《芙蓉锦鸡图》的工致观察和诗画呼应，不套用其具体形象。

**运动**：地点选中、面板展开属于有意义的反馈，沿用 180–240ms；地图定位沿用 600–900ms。纸纹、小景、印章保持静态；不飘落花瓣、不放飞鹤、不播放循环粒子。尊重 `prefers-reduced-motion`，减少运动时直接切换到目标状态。

## 七、改版先后与验收

| 顺序 | 具体工作 | 验收画面 |
| --- | --- | --- |
| 1 | 用本规范检查当前首页、阅读案、手机屏的截图，圈出“过光滑、过硬、过密”的位置 | 1440×900、1366×768、390×844 三张对照图；写明保留与修改处 |
| 2 | 调整首页地图周边留白、纸纹强度、地名标签和标题关系 | 地图先被看见；西部和东部点可辨；文字不压地理内容 |
| 3 | 调整阅读案标题、引句、小景、来源的顺序与细线 | 诗文清楚可读，画与题注相邻，不显卡片模板感 |
| 4 | 制作一张赵佶气息的原创小景样例，再扩展成至少山水、楼阁、关隘 3 类 | 线条、设色有共同规范，但三类各有物象特征 |
| 5 | 验收手机端、键盘操作、对比度与减少运动模式 | 地名可点，正文无纹理干扰，重要信息不靠颜色单独表达 |

**拒收信号**：全屏泛黄、明显纸张破边、每处统一印章、到处是鹤与祥云、所有地点都配同一座亭、把名画整幅贴作网页背景、把阅读文字做成瘦金手写、地图坐标为构图让路、史实图与意境插画不作区分。

**交付物**：一份可复用的项目设计令牌更新、一张首页与一张地点详情的高保真设计、三种地点小景 SVG、桌面／手机截图对照。此规范目前是设计依据；代码改动应在改版任务中逐项实施和验收。
