# 第一版运行后的批评与修整

2026-10-06。实际生产截图 `screenshots/round4/iteration-huxin-1440.png`、`iteration-huxin-390.png`；不是方案稿。

1. **纸纹被放大后像斜划痕。** 第一版直接把旧256纹理以512尺寸放在阅读正文，手机上在引句右侧可以辨认长斜线，材质先于字被注意到。改为独立阅读纤维SVG，原笔线拓扑不放大，透明度0.032、256px平铺；旧纹理与旧小景保存，地图底图不作过滤。复看最终截图，字与画优先于纸纹。
2. **同城其他锚点可能压住选中菱形。** 湖心亭和西湖共享原杭州城市参照，旧DOM顺序会让普通点盖到当前点中央。把当前菱形抬到文化标记层上，仍用同一矩阵原锚点；名称独立且朱色、轮廓和粗线一起表示选择，不移地理。
3. **手机关闭控件继承了34px宽。** 修为44px独立热区，不靠更细字腾空间。第一版390引句top574、bottom628.84，阅读案top422、bottom844，已进入未滚动首屏；维持21px引句，不缩到12px。最终另核对黄鹤楼长篇名与两作品切换。

仍需克制的地方：原全国图片中城市密，独立文化题注有浅纸背以保持对比；这块背板服务内容辨识，不延伸为每块渐变卡片。阅读没有四边框、阴影或重复印章。小景聚在建筑／疏树，水面有空，精绘程度与馆藏原作不能等同；借的是笔线轻重和图文关系。EPS注记分层与原有视觉粗边继续受限，不由CSS冒充解决。

4. **局部切换首帧有文字重绘异常。** 把地图内部控件隔离在地图绘制层，阅读案／站头拥有独立绘制层，局部导航、工具与地名也各有文本绘制层，视图切换时重建相应标题／工具节点；最后的局部截图等待MapLibre idle后拍摄，复核三尺寸标题可见。没有改相机、尺寸矩阵或地理数据。
5. **局部红点压到亭阁图标。** 实页看到红色地理点与图标左笔线相交，将屏幕题注向锚点外侧偏移12px。真实坐标和L7点层原位保留，类别符号与点可分辨；并非移动地理点。

最终批评：桌面主诗句和图画已相邻，手机引句在574–643px范围内，正文滚动区域到800px。平板半屏中小景下部需要正文滚动，这是诗句优先的选择；展开阅读可看全景。全国PNG城市密与边线视觉仍受限，不能以功能通过称全国底图美术全部完成。
