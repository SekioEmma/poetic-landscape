| 文件／职责 | 实际改变 | 使用上的作用 |
|---|---|---|
| `src/soft-interface.css`、`main.tsx` | 集中软边、色阶、字体和间距；纸案24、目录22、篇目16、来源20、照片12；正文保持18px | 一层读纸，正文不变成卡片网格；手机两侧露出地图，焦点仍可见 |
| `ReadingPanel.tsx` | 地名和三操作一行，导航／选篇一行；明确继续与恢复大小；抓手与标题空处指针捕获 | 固定区压到108px，全文获得空间；正文选择、滚动与链接优先 |
| `layout/reader-gesture.ts` | 8px起拖、48px慢拖最近档、0.45px/ms相邻档、取消及端点保护 | 最低档不误关案，鼠标与键盘共用三空间；纯逻辑取消测试不冒充设备触摸 |
| `layout/sheet-motion.ts` | 260ms真实布局矩形插值；中断读取当前矩形；revision取消旧帧；静观／系统reduce即时 | 外壳连续变化，字体不拉伸；反向操作不会跳回旧起点 |
| 阅读记忆 | 稳定后语义恢复；拖动／暂隐／移动时不覆盖记忆；短诗扩容夹住滚动位置时保留原锚点 | 同篇、同视图可回原位，专注短诗无需填充空白也能恢复常态进度 |
| `App.tsx`、`ExplorerDirectory.tsx` | 目录暂隐并inert读案，保留作品、tab和space；结果才选新案；取消旧退出timer | 只有一个主要信息面板；零结果Esc仍回旧文，新选择不被旧回调删除 |
| `MapControls.tsx` | 共用44×88缩放组与44复位，按可见地图矩形右下定位，冲突转右上 | 两种地图外观、触区与位置规则一致；操作不会躲进读案 |
| `OverviewViewport.tsx` | 沿用Panzoom／矩阵；稳定态才必要避让；手动相机优先；Esc不让隐藏预览截获 | 点、题注、正文对应，用户拖缩后读案切档不抢镜头 |
| `MapCanvas.tsx`、`MapAdapter.ts` | 共用工具回调；新增注记完成DOM事件；保留按需创建和单实例 | 局部首次才载入WebGL；工具跟随实际安全区，重入仍保留镜头 |
| `reader-layout.ts`、`useReaderLayout.ts` | 加实际安全区探针；底案宽度减24px；固定区预算纳入默认档判断 | 手机左右12px及安全区，不再贴满；短横屏默认收起，布局只有一个协议 |
| `OfficialOverview.tsx`、`SourceDialog.tsx` | 原图归入来源两步入口，保留GS、原件和模态焦点；展示实际第九轮两画来源 | 原件可查而地图不再堆一排重复入口；AI意境与真实照片区分清楚 |
| `check-reader-layout*.mjs` | 保留旧轮审计分支；增加新的Round10 DOM／时序／语义／失败记录审计 | 审计当前构建与新记录，不复制round9数据改日期；不会启动浏览器 |
