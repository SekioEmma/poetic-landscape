## 工作包1：2小时内决定素材路线

1. 在开始前保存本轮输入的源码／资产哈希、当前生产截图与主计划快照，保留可回退第十轮预览。
2. EPS的独立检查已发现大量路径，不能仅据第三轮“工具不可用”断言它没有矢量。检查现在已有的可信转换工具；可利用已可用的EPS→矢量PDF→SVG路径，或用户提供的矢量导出。此前Ghostscript下载／安装已被自动审批拒绝，不绕过或换包装重复被拒操作。没有工具时记录具体缺口后直接走L7路线，不等待安装。
3. 若能转换，检查图幅、边界、岛屿、特殊线、原标识、是否混入位图、城市文字是否已转曲；不要只找`<text>`就宣称注记可分层，也不能按路径大小删除“小物件”，那可能是岛屿。保存原件与转换结果对照、工具版本、参数、资产哈希。
4. 先证明矢量放大到4倍／8倍仍清晰，再证明地点定位方式。EPS纸面XY不是WGS84，禁止按图片矩形简单拉伸成全国经纬度。SimpleMap纸面模式只能在原坐标中作为矢量画布，不冒充地理配准；要用于正式经纬度探索必须有可靠配准／投影证据。不能把SVG包PNG、描摹PNG或把SVG栅格化进ImageLayer称为真矢量地图。
5. **选择一次主路线并记录，不在两条实现间来回重写。** 可靠转换、分层、定位及性能成立才采用官方衍生矢量；否则停止EPS路线，执行工作包2的L7全国地图。总计最多2有效工时，不把这个上限理解为必须重试安装两小时。

## 工作包2：全国地图进入L7，而不是仅局部使用它

推荐可落地路线：复用`MapAdapter.ts`的Scene／MapLibre初始化与生命周期，新增`NationalMapAdapter`和底图配置，L7点层管理文化点，L7／MapLibre矢量面线层绘制全国行政区。国家轮廓／省域、文化点、选中标记、必要参照文字和相机投影分层。也可整合到同一适配器，但不能仅为满足文件名新建空壳。

没有可靠EPS地理资产时，可用阿里云GeoAtlas全国GeoJSON做**本地学习与技术样板**：

- 入口：`https://datav.aliyun.com/portal/school/atlas/area_selector`
- 数据：`https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json`
- 官方说明：`https://help.aliyun.com/zh/datav/datav-7-0/user-guide/datav-geoatlas-widgets/`

本次调研接口返回35要素、约583KB，包括34个省级区划及`100000_JD`特殊要素。实施时重新核查、归档原始响应与哈希、本地加载；保留所有MultiPolygon环、洞、岛屿和特殊要素，不按名称空值过滤，不用简化世界地图代替。该数据来自高德、仅供学习交流，不是原EPS的直接衍生图，不得继承GS(2023)2763号作为新底图编号或声称正式发布许可已解决。把本地样板与正式发布来源状态分别记录。

将源坐标系和渲染坐标系写进配置。核实GeoAtlas数据的实际坐标约定；若为GCJ-02，正式地点／西湖WGS84数据只在渲染适配层转成一致体系，源文件不改，禁止直接混贴。至少核对成都、武汉、杭州三处控制位置，以及西湖局部亭岛位置；不能因全国尺度看不出偏移就写转换正确。若无法证实该数据适用，改用有明确条件的底图，不将疑似坐标系记成已验证。

正式来源更适合用天地图等官方服务时，MapLibre加载底图、L7加载文化点；核实实际接口、坐标体系、分级与版权／归属标识。配置用户自己的浏览器Key于本地环境文件，提供无Key示例，勿引用示例Key；浏览器Key会进入客户端请求，不能称环境变量让它对用户不可见。全国服务页`https://lbs.tianditu.gov.cn/server/MapService.html`，`vec_w`／`cva_w`为待实测候选。PNG型WMTS要明确叫分级栅格瓦片，不能因服务名称含“矢量”称客户端矢量。缺Key时继续做本地L7样板，不以缺Key退回本轮只修PNG。

底图来源接口应允许替换数据而不重写交互。`public/legal/basemap-manifest.json`和出处界面分别说明原件、官方衍生／GeoAtlas样板／在线服务、修改项目、坐标与版本。原官方JPG完整对照入口保留；当前PNG仅作WebGL／资源故障降级。主页面不展示技术调试字段。

优先单个可复用L7／MapLibre组合承载全国和已有西湖；全国／局部切换通过图层与相机完成，不重新创建地图。若当前兼容限制确需分别保留全国和局部两个实例，记录理由并采用懒创建、非活动实例停止渲染、复用不累加；实例数必须以生命周期计数证明，不能按canvas数猜。不要硬追单实例而毁掉西湖已验证几何。

首次加载可显示可阅读的轻量过渡态，加载失败目录与原文仍可用。地图不能等人点击“查看局部”才首次初始化全国引擎。读取已有MapLibre兼容桥，切换style后注意L7覆盖层不能丢失；禁止复制整套引擎或自行从零实现地图拖缩。

## 工作包3：地点显示规则与清楚的布局

依照全国地图规范实现以下初始值，调整时给对比证据：

1. 全国完整范围fit得到`z0`；相对缩放d<1为全国、1–2.5为地域、≥2.5为城市；阈值迟滞±0.12。全国最大zoom先限制在可支持的城市级，街道后置，已有西湖局部允许详细探索。
2. 聚合半径桌面48px／手机56px；聚合统计地点不是作品。同城组命名“杭州·2处”，跨省无共同地区时用“4处地点”，不得把江南逻辑写死。MapLibre GeoJSON聚合可复用，但其整数聚合层级与相对等级／迟滞要协调，不为凑效果并行做两套聚合。当前6处必须全部可到达。
3. 点聚合数量基于筛选结果。当前选中点即使筛选外仍独立显示，避免在聚合内外重复计数。点击聚合→相机fit成员；若成员极近／同位置、缩放后仍无法区分→打开一次紧凑地点列表，展示地名与关联诗篇数，选点进入读案，Esc／空白关闭并恢复焦点。
4. 数据点用真实地理坐标，不用旧图片城市锚点。西湖和湖心亭不可继续共用“杭州像素”。标记图形可以短偏移，但真正锚点不移动；不把同城几公里距离拉成假分布。
5. 标签优先：选中、键盘焦点／明确搜索命中、编辑重要度、普通点。稳定id排序，避免输入数组顺序改变布局。桌面全国／地域／城市标签预算8／12／16，手机4／6／8，选中点必须可识别。标签可隐藏但点／聚合可达；不按预算删除内容。
6. 优先引擎碰撞与variable-anchor能力；不得打开所有allow-overlap。选中标签可单独用一个DOM覆盖便于无障碍。安全区排除读案、搜索、地图工具、来源／归属区域。引线最多48px；放不下隐藏低优先标签，不扫描远处空白把地名拉走。
7. 文化文字16–18px，44px触区可透明；底图参照文字12–14px且按级别稀疏出现。全国底图不要几十个城市名同时铺满。桌面hover仅轻提示，明确点击才进读案；手机无依赖hover的步骤。

用隔离测试入口加载发布范围12点及40点压力配置（有重复／近邻／长名／边缘点），清楚标注测试且不进入正式内容。要在同一套规则中测试西北／东北／江南，不只为六点逐个特判。

## 工作包4：镜头与阅读连续性

使用相机适配层统一：`getCamera / restoreCamera / fitNational / focusPlace / fitCluster / setSafeArea / stop / resize / dispose`。类型可按项目组织；调用者不继续依赖PNG的x/y/scale。先列清地图事件→选点／阅读状态→相机意图的调用链，再迁移。

- 默认详情关闭，全国完整展示，包含原图对照时应有的区域／岛屿。提供等比例、无旋转、无倾斜的平面地图；默认镜头不能只fit当前六点导致全国范围缺失。
- 选点落在读案以外的真实安全区，沿用第十轮桌面地图≥55%宽、竖屏≥50%工作区高。通过相机padding／offset处理遮挡，不挤压地图DOM成窄缝。
- 飞行／聚合展开240–420ms；用户拖动、滚轮、双指或新选择立即stop并接管。自动阅读定位只在明确选择时发生；用户拖走后不循环弹回。
- 初次从探索进入阅读保存探索镜头；换诗、换地点和收起／展开读案不覆盖这份快照。阅读内手动探索独立保存；关闭读案恢复探索；局部返回恢复进入前全国阅读镜头。“看全国”仅复位，不能暗中关闭读案或清空搜索。
- 选篇、开出处、滚原文、切诗文／地点不触发额外飞行；当前点因面板尺寸改变被遮挡时最多必要纠正一次，并尊重用户手动相机。
- 正文滚动／选文不穿透到地图，读案手柄拖动不拖地图。全国地图滚轮、双击、触摸沿用引擎逻辑，触摸取消／旋转时状态能收尾。减弱动画关闭飞行与插值，状态／定位仍正确。
- 保留第十轮搜索暂隐读案、作品id／段落语义位置、三档读案、44px触区和18px原文；不得为了新地图推倒阅读结构。

## 工作包5：宋代地图视觉样板后再定版

先做1000与390两幅**实际地图**样板，取全国、江南中倍、黄鹤楼选中三态，写一页设计批评并修一次；不要先重做全站。复用现有纸色／墨色／朱色令牌，薄省界、清楚外轮廓、安静地名、已有细笔文化图标；无厚灰轮廓、浮雕阴影、持续脉冲和红色大气泡。低对比纸纹只铺在适当静态背景，不罩住地图文字和关键线条。宋代感来自比例、线描、设色与疏密，不靠全屏模糊或陈旧滤镜。

图源标識始终可查；新底图的署名不被面板遮挡，原GS号只说明原件。若使用栅格瓦片，视觉可调色但文字无法自由分层的限制写实，不宣称每个城市标签已经定制。
