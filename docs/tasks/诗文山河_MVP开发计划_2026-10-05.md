# 诗文山河：第一版 MVP 开发计划

版本：v1.3，2026-10-05。定位：从一张中国地图出发，在真实地理中逐层阅读经典。首轮已接入官方全国图片并完成湖心亭闭环；第二轮完善自由探索和6地点内容。具体进展见[首轮复核与第二轮任务](G:/project/数媒/诗文山河_首轮复核与第二轮任务_2026-10-05.md)，实施见[第二轮开发提示词](G:/project/数媒/诗文山河_第二轮开发提示词.md)。

**推荐方案：新建 React + TypeScript + Vite 前端，以 AntV L7 渲染文化图层，使用 MapLibre 适配器承载地图。主界面是中国地图及地点标记，点击地点才展开诗文；进一步查看局部地图、真实图景与历史介绍。首版精编12个地点、18篇作品、19条关联，提供自由探索和两卷主题阅读。保留原配色，以纸纤维、淡墨层次、疏密留白与细笔小景形成典雅、柔和、质朴的宣纸与宋画质感。**

这份文件保留完整MVP目标与最初排期，不代表全量软件已经完成。最初调研时尚未验证地图运行；当前首轮已完成锁定依赖的实际运行与湖心亭体验，第二轮启动前本窗口重新通过数据检查、生产构建和生产页面核心流程。已完成／未完成范围以最新复核及工程验收记录为准。

随附：[早期视觉方案板](G:/project/数媒/design/诗文山河_MVP视觉方案板.html)。保留其配色参考，但固定分栏、光滑表面与硬边框不再作为布局和材质标准；本轮未修改该HTML。地图图形为布局示意，不是正式底图；湖心亭插画不是历史建筑复原。最新要求以本计划及[首轮开发提示词](G:/project/数媒/诗文山河_首轮开发提示词.md)为准。

## 1. 用户体验与完成目标

进入页面首先看见中国地图和地点标记，无默认展开的诗文卡或常驻宽目录，无需等待开场动画。点击“湖心亭”或杭州组中的湖心亭，地图聚焦并展开阅读案，列出相关诗文，读到“长堤一痕、湖心亭一点”；可展开完整原文与出处，再进入“此地”查看局部地理、今日照片与地理辨析，进入“沿革”查看有来源的历史介绍。关闭详情或点击“返回中国地图”恢复总览视野；从一个地点直接切到另一个地点无需先退出。

三层体验依次为：中国地图总览 → 地点与关联诗文 → 局部地图／真实图景／历史介绍。两卷主题阅读是总览上的另一条探索路径，仍复用相同地点详情，退出后回到地图。历史内容、照片与局部地图按资料完备程度接入，不凭空填满。

用一次3分钟体验，回答三个问题：这段诗文写到哪里？为什么这里成为文学景观？它在地图中代表的是古址、现代展示地点还是大致区域？

**首版的原创工作**集中在精编内容及地理辨析、自有视觉与插画、地图—文本联动、主题卷编排。技术选型和作品数量不作为创新本身；参赛说明应展示原有参考能力与本项目新增能力的区别。

### 开发底座的决定

新建轻量项目而不是 fork poetrymap 整站。原因是当前数据已经重新精编，地图引擎及视觉也都要更换，迁移其路由、地图组件和配色没有明显收益。底座是 L7 的渲染能力；poetrymap 和故事模板是信息结构及交互参考。

## 3. 美学方案：清润山河，细笔入景

**视觉细则更新**：具体的赵佶与宣和画院参考、纸感转译、颜色和排版规则、首页及阅读案验收，见 [《诗文山河：宋代美学与赵佶视觉规范 v1》](design/诗文山河_宋代美学与赵佶视觉规范_v1_2026-10-05.md)。本节保留为 MVP 范围概要；前端改版以细则为设计依据。

文人画、院体绘画、工笔技法不是同一个概念。此方案取文人审美中的诗意和空间节奏，参考宋代院体作品的构图、物象观察与细劲线条，并以当代界面方式组合。**“宣纸感”是界面材质选择，不把所有宋画说成宣纸上的水墨画，也不以黄色做旧等同于宋代美学。**

### 四个可核查的绘画参考

| 作品与机构资料 | 实际参考要素 | 转译为界面与资产 | 不直接照搬的部分 |
|---|---|---|---|
| [王诜《渔村小雪图》](https://www.dpm.org.cn/collection/paint/234606.html) | 雪后山水的层次和渔村生活的安静气氛；本次以官网检索资料为研究入口，未逐段鉴赏全卷 | 湖心亭及西湖篇的冷静浅色，点景舟、人和岸线的尺度 | 古画扫描的陈旧色、收藏印和图像本身 |
| [马远《梅石溪凫图》](https://www.dpm.org.cn/collection/paint/234350.html) | 实际查看图像与官网说明：对角线构图、偏角的树石、小尺度点景 | 主视觉集中一侧，另一侧留给文字；小插画密中有疏 | 马远为画院画家，不将此图笼统称作宋代文人画；不复制其具体构图细节 |
| [《芙蓉锦鸡图》](https://www.dpm.org.cn/collection/paint/230125.html) | 官网记绢本设色，细劲双钩与层次设色，署名归属还有辨析 | 芦苇、梅枝、舟、亭的细线和少量设色；题字与物象相互呼应 | 不把所有署赵佶作品简单断言为赵佶亲绘；不使用博物馆原图充作自有素材 |
| [王希孟《千里江山图》](https://www.dpm.org.cn/collection/paint/228354.html) | 青绿山水与长卷观赏的参考；本轮正文打开超时，依据官网检索及专题材料 | 地点选中使用少量青绿，章节像展卷一样逐段进入 | 不把整个地图填成高饱和蓝绿，不据画卷形状替代真实地形 |

博物馆图像用于观看研究，正式界面优先采用原创 SVG 和自行制作的纸纹。若需要原图，先落实相应影像使用条件；本计划不依赖获得原图授权才能完成。

### 色彩与层次

以下色值是为屏幕设计的建议，不是对宋代颜料的历史还原。

| 色彩角色 | 色值 | 用法 |
|---|---|---|
| 纸底 | `#F4F0E6` | 页面、地图背景 |
| 近白纸 | `#FCFAF4` | 阅读面板，纹理比地图更淡 |
| 主墨 | `#2E3430` | 原文、地名、标题 |
| 次墨 | `#60685E` | 作者、说明、状态 |
| 青绿 | `#506553` | 选中点、主题入口、焦点边框 |
| 水色 | `#A8BBB9` | 江湖的低饱和面与细线，非小字颜色 |
| 赭朱 | `#8D5044` | 少量章号、选中印记、关联句线条 |
| 纸边 | `#D7D6CB` | 分隔线与轮廓，非正文 |

画面至少75%的区域保持浅底和留白。深墨用于内容，青绿和赭朱承担有限的视觉强调。普通文字对比度目标至少4.5:1；水色、边线色不承担关键文字信息。

### 最新设计要求：从光滑界面改为纸上山河

保留配色，重新处理材质和构图。用低对比纸纤维、微小色差、淡墨疏密与轻薄设色建立质感，避免平均铺噪点、浓黄做旧或破损纸边。减少连续硬边分栏、规整方框、胶囊按钮、明显投影和厚重矢量色块；阅读案靠留白、淡墨短线和文字层级组织。柔和不是给所有组件加大圆角。地理边界依照真实数据，墨色变化仅影响呈现，不改变形状与点位。

真实照片在详情中像展开附图，保留自然色彩，不统一加水墨滤镜。插画、今日照片与历史复原明确区分；首版不制作历史复原。纸感与宋画构图优先服务阅读和地图识别，不能让装饰淹没地点与正文。

### 材质、字体、插画、动效

- **纸纹**：原创静态重复纹理，推荐256px瓦片；强度2%–4%，阅读区0%–2%。第一版可以用静态SVG噪声／少量细纤维试验，正式实现优先烘焙静态纹理，避免全屏持续滤镜消耗。画布覆盖层必须 `pointer-events: none`，不阻断地图操作。
- **字体**：标题及诗文采用思源宋体的厂商简中版本，操作信息采用系统无衬线。保留 [Source Han Serif 的 OFL 许可证](https://github.com/adobe-fonts/source-han-serif/blob/master/LICENSE.txt)，先用系统宋体保证首屏；自托管字体按需加载。不使用来源不清的商业书法字体。宋体字体名称不是宋代书法还原声明。
- **字号**：标题桌面36–48px，阅读标题26–32px，原文18px／行高1.9，说明16px／行高1.7，辅助字13–14px。地图地名14–16px，选中地名不靠单独变色区分。
- **排版**：桌面精选名句可短行竖排，完整原文横排；手机统一横排，避免长文竖排造成阅读困难。白居易、苏轼等跨篇作品按作者和篇名明确标示。
- **图标**：先做楼阁、寺桥、亭岛、山岳、渡口、关隘6种细线图标；全国／区域总览用少量通用符号，选中才出现精绘小景。单色线宽在屏幕上保持约1.2–1.6px，避免过细消失。
- **精绘小景**：首批湖心亭、黄鹤楼、大散关3张原创SVG，分别覆盖亭岛、建筑、关山。它们放在阅读面板或选中局部，不铺满所有地点，不宣称古建精确复原。
- **动画**：按钮与面板180–240ms，地图相机600–900ms，保持二维视角；取消旋转、连续波动、全屏粒子和默认自动播放。尊重 `prefers-reduced-motion`，提供无飞行动效切换。
- **声音**：P1，默认关闭，由用户手动开启；古诗里有钟声不代表需要全站循环背景音乐。

## 4. 页面与交互规格

### 桌面：中国地图为主，点击后展开阅读案

推荐适配1440×900，兼容1366×768。地图占据顶部约56–64px之外的主要视野；标题、搜索、主题与地点目录入口轻量叠放。默认目录收起、详情关闭，不采用固定左目录＋中地图＋右阅读案的三栏首页。选中地点后右侧展开约380–440px阅读案，较窄桌面可使用覆盖面板；相机视野计算要避开面板，地图主体仍可操作。

地图：纸底、真实海陆和适量水系、克制的地点标记；装饰小景独立于地理图层。同城的西湖与湖心亭在低缩放级别合并为杭州组入口，点击展开组内列表。目录作为抽屉或浮层提供等效入口；选中后地图、目录和诗文同步。提供显眼但克制的“返回中国地图”，关闭详情恢复总览范围；直接切换地点保持最后一次选择，过期相机动画不得覆盖新状态。

地点详情提供三项内容入口，默认“诗文”：

- **诗文**：地点名、今地与空间精度、相关作品列表、作者／篇名、关联句、80–150字人工解读、完整原文与出处。同一地点支持多篇作品，湖心亭首轮可以只有一篇。
- **此地**：将同一地图切到具备足够精度数据的局部视野，并在面板展示空间关系说明、真实照片与地理辨析。缺少局部数据时保留可核验区域视野与精度提示，不放大粗尺度数据伪造湖岸。不另挂第二个地图实例。
- **沿革**：简短历史介绍和可追溯来源，说明诗文时代与今日景观的关系。只有核验时间才写入时间线；首版不强制复杂时间轴或历史地图切换。

照片标注作者、来源、许可、拍摄时间（未知则明确）、图注。出处可展开书目或网页、关联类型与未解决项；精度提示用自然语言，不展示内部字段名。

### 手机：总览起步，点击后阅读优先

顶部约56px，默认地图充满余下主要视野。选点后出现半屏／近全屏底部阅读面板，半屏时地图保持可见；“诗文／此地／沿革”可切换，完整原文横排。关闭详情回总览，支持清楚的返回键与地点列表入口。目标触控区域至少44px，390px宽度无横向溢出；照片按需加载，详情打开不能导致地图空白。

### 两卷主题阅读

| 主题卷 | 章节 | 时长建议 | 核心联动 |

| 水上清音 | 西湖晴雨 → 湖心亭雪 → 枫桥钟声 | 约90秒 | 相机切到对应区域，选中地点，改变小景和关联句 |

### 发布前每条必填

**用户最新执行偏好（2026-10-05）：** 坐标采用主流认定地点或现代景区位置，记录可靠来源与坐标系即可推进，不开展米级或古址精确考证。正常界面不反复强调“非实测”“落笔点未考定”或资料缺口；技术方法与限制移入出处页，只有影响理解的地理差异在正文简短说明。后续表格中的精度与审核记录是内部数据要求，不要求重复显示给用户。

| 数据集 | 字段与要求 |
|---|---|
| places | 稳定id、名称、审核别名、现代区域、主题、类型、人工解读、辨析、sourceIds、reviewStatus |
| geometries | placeId、Point／范围、锚点用途、空间精度、来源、原坐标系、标准化WGS84结果、核验记录；未知则不伪造 |
| works | 稳定id、作者、时代、文体、题名、完整原文、文本底本、异文说明；创作年未知可空 |
| relations | placeId、workId、关系类型、原文高亮片段或段落id、证据来源、审核状态；“描写”不等于“到访／创作” |
| placeDetails | placeId、局部视野及适用尺度、地理说明、短沿革、历史事项及sourceIds、mediaIds、各项资料状态；现代照片不作为古址证据 |
| media | placeId、文件／可用入口、类型、图注、作者、来源页、明确许可及署名要求、拍摄时间与所示年代；未落实使用条件的图片不打包 |
| stories | 卷id、标题、章节、placeId、workId、精选片段、相机建议、显示图层、章序；默认非历史行程 |
| sources / assets | 标题、机构／作者、URL或书目、读取范围；资产作者、许可、来源、用途、AI使用记录（如实际使用） |

文字高亮用段落id＋精确片段匹配，验证片段确实存在于所用原文，不依赖全站简单地名替换。搜索别名只服务查找，不自动新增地理实体或作品关联。

坐标阶段按“区域可定位 → 现代展示点 → 古址证据”分别审核。若仅有现代景区点位证据，就清楚标明现代参照，不宣称古代落笔点。坐标系必须记录，不将地图供应商的GCJ-02点位直接与WGS84图层混合，也不以未经验证的转换公式填补来源。

**硬性规则**：缺少完整原文底本、关联句验证或出处的条目不发布；古址精确位置未解决时可使用经过核验的区域显示，但不得使用假的精确坐标。12个条目是否达到发布要求在10月9日检查，数量不足时按第9节降级。

## 6. 技术实施方案

### 前端与地图

- React + TypeScript + Vite，静态JSON数据，CSS变量；不建立服务端数据库。
- L7 Scene管理文化图层，MapLibre负责相机及基础地图；通过 `MapAdapter` 把相机、选中、图层显隐和销毁集中管理。
- 2026-10-05 npm registry查询：`@antv/l7` 与 `@antv/l7-maps` 均为2.29.1；其地图包声明的 `maplibre-gl` 依赖为 `^3.5.2`，独立MapLibre最新版本为6.12.0。**不能因为独立最新版更高就直接换上6.x。** 首日以L7配套依赖为起点，验证后锁定实际包版本及lockfile。
- Vite查询到8.3.2，Node要求 `^20.19.0 || >=22.12.0`；本机现有Node v22.17.0符合此要求，可作为首日验证环境。React版本与脚手架配套锁定，不将升级到最新版列为任务。
- 主分支源码存在 MapLibre 导出不是“已验证发布包可运行”的证明；以安装后最小样例和生产构建为第一关。

首轮实际结果：工程已锁定MapLibre 6.12.0、L7/l7-maps 2.29.1及兼容桥，并完成具体组合的运行验证；上述版本建议保留为最初选型背景。第二轮沿用已测组合，不重新升级或退回3.x，兼容桥边界见工程 `docs/兼容性与资料缺口.md`。

### 主底图：中国总览与局部视野分级

**2026-10-05首轮实际接入：** 用户已提供“中国地图，1∶1000万，对开，界线版、无邻国、线划一”的JPG与EPS，图面GS（2023）2763号已由首轮核对，完整JPG已用于全国图片总览，本次数据检查也通过原件与运行资产哈希校验。具体来源与实际改动台账见[官方底图来源与改动说明](G:/project/数媒/诗文山河_官方底图来源与改动说明.md)，旧[官方底图接入提示词](G:/project/数媒/诗文山河_官方底图接入提示词.md)为已执行阶段。静态原图没有可靠投影依据，现采用完整图片总览与L7局部视图切换，不重做该任务或猜测配准。实际下载URL与时间尚待补充；保留原底图号不代表项目叠加、处理及交互成品已经审核。

MapLibre读取本地style和GeoJSON，L7叠加文化图层。总览首屏覆盖中国完整展示范围及必要周边，不再只裁切首批地点周边。中国轮廓、边界与岛屿采用经过核验、来源和使用条件明确的资料；记录版本、展示范围、简化方式与核验情况，不手绘、拼凑或直接把未经核验的国外行政数据当作中国标准图。正式全国地图资料未落实时，开发样例明确记录缺口，不能宣称已完成总览验收。

[Natural Earth自然地理数据](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-rivers-lake-centerlines/) 可作为自然海陆、主要河湖的候选素材；官网说明数据属[公有领域](https://www.naturalearthdata.com/about/terms-of-use/)。它不是中国边界依据，也不替代局部高精度资料。下载后保存来源与处理脚本；其中10m表示约1:1000万制图尺度，不是10米空间分辨率。

总览不强制省界、路网或城市建筑细节。局部图首版仅重点实现湖心亭，采用另行核验的西湖及相关地物资料，表达亭与湖域的真实空间关系；来源不足时只展示可核验区域定位及说明，局部地图验收保持未通过，不用原创小景替代真实湖岸。其他地点按资料条件扩展，不要求全部提供街道级地图。

总览用fitBounds及面板避让适配桌面与手机，而不是固定缩放值。MapAdapter按overview／local切换数据与允许的缩放级别；粗尺度层到达上限不继续当作精细地物放大，局部资料验证后才能开放对应深度。返回总览恢复全国视野、清理局部层并保持同一Scene。

使用本地底板的目的在于让纸色和水色可控、演示可运行、避免外部瓦片密钥失效。正式交付前仍审核地理表达；公有领域许可本身不保证地理正确。

### 视觉与性能

- 在1440×900、1366×768、390×844及768px宽度截图复核；无标签严重重叠、文字裁切和横向溢出。
- 首页地图为主、详情按需出现；纸感不是统一噪点与做旧，界面没有大面积光滑硬框与强投影；照片自然色彩、图注可读，装饰不改变地理形状。
