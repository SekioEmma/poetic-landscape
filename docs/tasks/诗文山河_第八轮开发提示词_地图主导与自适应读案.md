## 按顺序完成

### 1. 先统一布局判断和空间状态

采用常态阅读、收起题签、主动专注三种受控状态，避免叠加多个布尔值。默认选点为常态，短高度确实无法同时读文与看图时默认紧凑题签并明确阅读入口。收起保留地点／作品／视图／阅读锚点与手动镜头；×关闭才恢复进入前探索视野。专注恢复回同一常态案，不开新modal／路由，不复制全文。

审核所有硬编码1024判断，包括App compact、ReadingPanel动画、OverviewViewport安全区／题注／列表、MapCanvas控制及地图适配器、CSS。侧案／底案依据同一布局协议。初始条件可采用W≥1100或W≥800且W/H≥1.15；1000×750、1024×768必须侧案，768×1024底案。转屏／边界resize保持当前选择、篇目、视图和语义阅读位置。

### 2. 实现窄侧案和竖屏半高案

1440侧案约400–420px，1280约380–400px，1000／1024横向约340–360px，844×390约320px。常态地图可用宽≥55%，手机横屏最低≥50%；案内原文18–20px、作者／操作≥14px，长题名换行。

竖屏案按页头以下工作区T的约45–50%计算，不再64／66dvh；上方有效地图高度≥50%T。平板可将案限制约600–640px宽、居中以收住空纸；手机满宽、内距20–24px。固定区保留第七轮精简结构，不添加工具行；全文始终在唯一正文中可滚动，不重新折叠原文。短高度无法给约220px正文时使用收起题签，不缩字。

专注仅由明确“展开阅读”进入：横向约560–640px并限制比例，竖向约90–96%T；操作“恢复分屏”清楚返回。收起题签显示地名、当前篇目、继续入口和关闭，约88–136px高。常态案提供明确收起操作，不让点击地图空白偷偷关闭阅读。

先做黄鹤楼和湖心亭样板，实测后复用其余4处；不要一边修布局一边重写原文内部信息架构。

### 3. 同步地图实际安全区

全国图和局部L7都按实际地图、页头和案矩形决定安全区；不要只改CSS让地图继续猜底案。当前锚点与题注在可见区，工具可点、分组列表不被盖住。案状态转换只做必要避让，不每次自动重置缩放；用户拖图可打断，手动相机与探索恢复协议保留。ResizeObserver不得形成相机反馈循环。

阅读滚动与地图滚轮／拖拽边界清楚；收起的正文不留可Tab的隐形控件；专注态地图控件如不可用需正确隐藏／移出焦点。沿用单实例L7懒加载，状态变化不重建地图。原图、几何、六原图片锚点与来源标注不变。

### 4. 只做与构图相关的宋代视觉修整

浓墨篇名／正文、次墨作者与资料；题签尺度克制，纸案边界轻柔，静态纸纹低对比。窄纸案收住短诗旁的空白，留白放在联间与题诗关系。保留现有小景并后置，不用大画、重复摘句、重阴影或一排药丸填空间。不要把系统宋体改成来源不清的瘦金体，不新增图像生成。

真实截图批评必须同时看地图与案的全页构图，不能只截阅读案内部就宣称视觉达标。全国粗边／密注记和湖景工笔差距继续分别记录；本轮不重试无新条件的EPS／Ghostscript安装与旧受阻清理。
