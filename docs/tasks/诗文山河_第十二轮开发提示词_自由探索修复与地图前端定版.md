## 三、A包：先修原生手势与自动镜头冲突

### 已复现的失败

独立浏览器在桌面连续四次滚轮放大，zoom保持2.3262563305924218；390竖屏四次后仍为1.8287518669172957，mapTrace显示四次user-takeover。230px长拖动地图只移动约29px。单击＋能增加0.5，因此不能用按钮测试代替手势。

首先检查 `src/map/MapAdapter.ts:42–51、115–117`：pointerdown／wheel／dragstart／zoomstart均无条件stop；锁定MapLibre6.12.0公开Map.stop会停止处理器。**公开Map.stop不接受allowGestures参数，不要直接改成map.stop(true)**；也不要调用私有_camera、改node_modules或打全局原型补丁。

### 实施要求

1. 区分应用发起的自动镜头与原生手势。可用一个小型镜头意图／序号记录，来源包括选点、分组、看全国、恢复、缩放按钮；无需新增大型状态库。
2. 将“标记用户已接管／取消过期自动意图”和“停止正在执行的自动动画”拆开。dragstart／zoomstart不能再次停止原生处理器。手势已经开始后，连续wheel事件不能反复重置它。
3. 如需在输入开始时取消自身easeTo，依据当前版本公开API和事件顺序，仅在确认自发动画仍运行时处理一次，并在引擎开始该手势前完成；后续原生帧保持完整。用真实输入验证，不靠推断。
4. 自动定位的异步回调、reader-settled、安全区纠正等遵守最新意图。用户拖动后旧回调不能突然拉回选中地点；快速换点只保留最后选择。resize只修容器／图面可见性，不在手动探索时重新fit选中点。
5. ＋／−短时间连按依据累计目标缩放，而非每次从尚在动画中的瞬时zoom计算，避免10次点击只有一次效果。原生滚轮围绕鼠标锚点；按钮以实际可用地图区域为视觉中心，不能向被读案挡住的视口中心缩放。
6. 核对L7 marker容器、地图canvas、纸纹、地名、页头、工具和读案的命中层级。无交互装饰透传；文化地点按钮和列表正常点击；读案正文滚轮只滚阅读区，读案外滚轮只缩地图。局部图同样修复，不维护另一套冲突手势。

A包出口：真实连续滚轮、持续拖动、自动定位中抢操作通过，才能进入后续视觉实施。补一个针对自己相机调度的必要回归即可；纯函数测试不能宣布原生手势通过。

## 四、B包：缩放尺度、镜头及地点显示

### 1. 全国探索尺度

- 删除目前全国7.5上限造成的过早止步。先试验全国上限11–12，选择能分辨文化地点又不误导为有街道细节的档位，集中到配置文件，并说明最终选择与真实截图。西湖局部保留自身上限与地理层。
- 全国底图是省域矢量，放大不会凭空产生道路和建筑。高倍继续显示真实文化点及必要地点／区域文字，不伪造街道、不把空白说成详细地图；如果需要更多底图细节，作为明确后续数据工作记录。
- 最小缩放按当前全国适配值允许再退约0.25–0.5级，实际确认不裁切完整范围；达到边界时按钮禁用／反馈一致，不让用户猜测卡住。
- 自由平移可探索全国任意区域，不能由现有六点bbox限制。防止无限漂移到无意义空白，但不可硬锁选中省份；看全国为主动复位，点诗篇／滚原文／关闭目录都不重置镜头。
- 全国完整适配按真实可用图面与投影计算，复核1280桌面初始偏右的问题。不得通过剪南海部分、删特殊要素、挪点或改源几何换取构图；桌面可保留题诗留白，但地图主体与留白应有明确比例。

### 2. 四层信息与稳定密度

| 尺度 | 主信息 | 规则 |
|---|---|---|
| 全国总览 | 完整山河形状＋文化分组＋少量省域定位 | 分组先给数量，能可靠概括区域时加短区域名；跨大范围组不误称同城，点击放大到成员范围 |
| 省域／区域 | 独立地点名称，必要区域名称 | 分组逐步展开，文化点优先于省名，当前选择和搜索结果优先；名称不随每帧随机翻换 |
| 城市附近 | 同城近点和短名单 | 用真实聚类成员列出地点、地区与篇数，清晰选中项；选择后只进行必要定位 |
| 明确局部模式 | 西湖水域、堤岸、真实近点 | 显式入口才启用，返回恢复进入前全国阅读镜头；全国放到高倍不暗中切局部模式 |

沿用当前碰撞／标签预算并修选择策略：省名按当前可视区域和观看中心排序，不按GeoJSON文件顺序截前几个；地图运动中保持少量关键锚点，稳定后补文字。使用迟滞和稳定键减少临界缩放闪烁。不同视口不要求相同标签数，但必须有规则。

六点、12点与40点隔离压力配置都检查；测试点不混入正式发布库。保持地理锚点不动，必要图标位移须有短引线；不因避让把玉门关移动到别的地区。列表计数与筛选后的实际地点一致，按地点数而非作品数。

## 五、C包：地图主画幅与宋代前端定版

本包依据[Anthropic界面与宣和美学规范v2](G:/project/数媒/design/诗文山河_Anthropic界面与宣和美学规范_v2_2026-10-08.md)，实施Anthropic式清晰任务组织与宣和画谱式诗画关系；修外层布局，不推倒已合理的原文结构。

1. **先写设计依据。** 原图观察至少两件：优先《蜡梅山禽图》加《竹禽图》／《瑞鹤图》，馆藏入口见新规范。每件写具体构图、线条／设色、题款关系以及在页面哪一处落实；打不开就说明并改用能看的馆藏，不伪写通读专著或已看原图。
2. **统一五态。** 桌面与390竖屏画出全国、地点常态、收起、专注、搜索；标一个主对象和主操作，明确所有返回结果。黄鹤楼短诗、杜甫草堂长文各走通，再统一六处外层组件；本轮不再扩画。
3. **主画幅和轻读案。** 地图宽／高约束保留；桌面读案先试360–420px，实测1000／1024／1025边界；手机收起72–96px，常态地图高至少工作区50%。页面无目的空洞需要纠正，不把超大空白称宋画。页头保留轻站名和一个主要搜索入口，来源主入口与必要署名职责清楚。
4. **去重复容器。** 读案一层纸面和18–24px软边；近点名单12–16px起点，工具44px触区；原文／解读／底本无重复厚卡。界面柔和由层级、边缘、间距共同形成，不统一大圆角或统一直角。任务入口、文字标签、工具和信息行各有形态。
5. **明确宋代气质。** 薄青省面、清楚国界、退后省界、细笔点景；选中地名与朱色是一套状态，避免红点／粗图标／白卡／下划线同时抢眼。《宣和画谱》山水重位置，花鸟重诗意与物象情态：先定图文位置，画作围绕诗篇，不用通用花鸟。保留纸质阅读底，但不把绢本设色说成宣纸水墨复原。
6. **稳定可读的字体。** 原文18px与工具44px保留；大标题不重复竞争，地图地名14–16px，省名和辅助信息次级。瘦金体仅授权后少量题签；工具无衬线、阅读宋体，不用细淡小字或过大字距表现古意。
7. **明确而短的动效。** 工具反馈120–180ms、读案180–240ms、主动定位240–320ms为试验起点；用户反馈立即，快速输入可打断。原生地图不叠CSS transition；原文稳定，不逐字入场、循环花瓣／飞鹤。展开／关闭来源方向清楚，减少运动模式无非必要位移。
8. **按真实成果批评。** 同尺寸、同地点、同篇目保存实施前后截图，指出容器减少、图面比例、密度、纸感／线色三项以上具体变化。完成S01–S05审美证据，不以skill已调用、构建或圆角变化宣称宋代风格通过。
