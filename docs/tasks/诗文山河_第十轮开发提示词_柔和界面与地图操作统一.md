## 2. 柔化读案并压缩固定区（约2–3h）

在`ReadingPanel.tsx`及CSS落实规范：外壳24px、轻阴影、不描四边重线；手机左右12px及实际底部安全区，不再宽390贴满390屏。保留原文18px和连续纸面。

将当前“44px工具＋30px地名＋44px标签”改为两行：**地名和收起／展开／关闭**一行，**诗文／地点与篇目**下一行；手机grabber和热区纳入整体预算，固定区目标≤108px，360长地名上限116px且记录实测。收起／展开用线条图标、title、aria-label；触区44px。`恢复分屏`改`恢复大小`，collapsed仍有清楚的“继续阅读”。长地名与李白长题名完整可读，不能缩小字或挤成一排小字。

篇目浮层用14–16px软边及选中标识；原文、解读、地点段落不再新增四边框。来源／原图弹窗及搜索容器使用规范的第二级形态。照片只柔化显示容器，原文件、比例及署名不变。保留键盘焦点；注意外壳裁切不能把篇目浮层裁掉，必要时将浮层放到独立定位层并维持焦点关系。

交付该包时1000、390两张**真实实页**必须已能看出边界和固定区改变；若仍像直角面板，仅改了按钮几个角，本包不通过。

## 3. 统一地图工具和搜索层次（约2–3h）

抽出共享地图工具外壳（建议`components/MapControls.tsx`），分别传入Panzoom／L7现有回调，不增加引擎。44×88圆角缩放组＋单独44px复位，跟随`mapReadingArea`的可见矩形放置，默认在可见地图右下；选中地名冲突时转右上。全国、局部相同位置与外观、正确aria-label。通过移动工具避让，不能移动真实地理锚点。

局部左上常驻轻胶囊“回全国”，点一下切回；不要求去地点正文滚动找返回。全国原图对照归入统一出处入口，最多两次点击能查看原件。不得隐藏审图号说明或删原图按钮而无等价路径。

复用现有顶栏“寻诗文”入口，改为有搜索图标和提示的软边入口：桌面约260–300×44，手机约96–120×44；不要为了搜索额外占一条大横栏。打开后输入、清空、主题和结果仍使用既有数据检索逻辑。列表按留白排布，当前点轻底色，主题选中采用小软底／可见标识。

**目录打开时暂隐读案并保存其空间、篇目、tab与语义位置；关闭目录恢复原案；选择结果才转入新案。** 桌面不同时留下左右两个大主要面板夹地图。保留目录既有modal判断、inert、Tab焦点边界；临时隐藏读案不能触发正式关闭和探索镜头复位。零结果／当前筛选外阅读照常可恢复。

## 4. 三档面板与可打断动效（约3–4h）

基于现有collapsed／reading／focused一个状态来源实施，不另造CSS断点或独立“半展开”业务状态。手机／竖屏加grabber：仅标题非按钮空处／把手起手，正文原生滚动不收案；小位移不误切档，取消手势／旋转可收敛。三档停靠、速度阈值、键盘替代遵循规范；最低档保留当前阅读，×显式关闭。

当前代码仅先换终态width／height再平移；本轮补**外壳尺寸或可视裁切随过程连续变化**。桌面不得把文字scale拉伸；可实际插值width、用布局隔离与稳定后语义恢复，或使用能保持文字尺寸的裁切方式。手机纵向变化可采用稳定内容与外壳裁切，避免正文抖动。

采用240–280ms主过渡、80–120ms反馈、规范缓动。第二次操作从当时可见状态接续，最后意图优先；旧关闭timer不能删新点。地图安全区终态修正最多一次必要镜头移动，不每帧fit；地图拖动立即接管，取消尚未完成的自动镜头。位置记忆、局部单实例、搜索恢复及原图模态均复用。

最上层Esc合同延续：原图／出处→选篇→目录→关闭读案。正文／下拉／目录滚动不触发地图缩放。静观与`prefers-reduced-motion`关闭位移／弹性但不禁操作。若工具不能合成连续拖动，只写“按钮与键盘档位实测；连续指针／触摸未测”，不能拿点按钮假称跟手手势通过。
