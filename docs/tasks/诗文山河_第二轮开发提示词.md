## 实现任务

1. **通用数据与阅读组件。** 将单一work改为places、works、relations与地点详情结构，稳定id关联；作品只保存一份。选中地点后得到它的作品列表，支持切换，作者／标题／名句／全文／高亮／出处一起更新。拆出可复用阅读、作品切换、此地和沿革组件，不继续扩展湖心亭硬编码大分支。复杂状态库和后台不需要。
2. **全国入口与分组。** 为6处接入官方图片锚点。杭州组包含西湖和湖心亭，点击先选组内地点；其他近邻标记若碰撞，采用简单组入口或短列表，不挪动底图地理内容。图外目录始终提供全部6处入口。增加城市或简短地点名称提示，不能只留下难以辨认的数字。保持原图全幅、等比例、署名与审图号。
3. **搜索。** 查询地点名、常用别名、作者和篇名；例如“杭州”“苏轼”“枫桥”“茅屋”返回相应地点。地图入口、分组列表与目录复用同一结果集；空结果、清空、与主题组合都可用。点击匹配作品后优先打开该作品，避免找到苏轼却显示白居易。清空查询不无故关闭正在阅读的地点；过滤后未在结果内的详情可以继续读，但要避免地图仍标成匹配结果。
4. **主题筛选。** 全部、楼台与城郭、江湖与行旅、山川与隐逸、关山与家国。地点主题按文学内容确定，允许多主题，作品时代与地点类型不混淆。当前没有结果的主题可禁用并说明，不能伪造内容凑齐。与搜索组合，同组剩余一个地点时仍能直接选。
5. **简洁的深读。** 湖心亭保留局部图和照片；西湖可复用同一局部层，配置自己的观察范围与说明，不能沿用湖心亭选中标题。其他地点的“此地”至少有位置与景观介绍，“沿革”是可读文化内容；本轮不强求新局部数据或照片，无资料模块直接不显示，不展示大段开发缺口。来源可查但不压过诗文。
6. **地图为主的视觉微调。** 保留宣纸与宋画气质，压缩首页引导文字和外围空间，让完整中国地图占据更大可用高度。不要裁切、滤镜改色、重绘官方原图，不做全面视觉重建。6地点图例不能在手机堆成多行挡住画面；放进可收起目录及分组入口。重点做好阅读层级、作品选择和地图入口识别。
7. **按需初始化局部图。** 首页仅看官方图片时不提前加载并初始化L7／MapLibre。第一次真正进入局部地图后初始化，随后保留一个可复用实例；全国回退时隐藏、清理局部状态。独立/map-lab仍能初始化。局部加载或渲染失败时诗文、目录、全国原图仍可用，切换到无局部图地点不让旧湖心亭图残留。记录首页是否有canvas及局部进入后的实例数，不只改成表面动态import。
