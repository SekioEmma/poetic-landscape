## 2. 按依赖实施四个工作包

### A：整理标注身份、测量与排布

先审 `MapAdapter.annotations()`、`national-config.ts`、`national-map.css`、`exploration-interface.css`。将可单独验证的候选选择与碰撞计算整理为小模块，渲染、地理相机与正文不要一起重写。

区分geo anchor、visual icon、text box、44px hit target；正常图标留在真锚点。先换文字位置，真的近邻／同坐标改用聚合或名单，禁止为了防碰撞给普通图标永久随机移44px。

为placeId／稳定成员集合缓存上一文字候选和DOM节点；合法时沿用，冲突才换。当前选中／焦点、搜索、普通、省名按规范排序，包含真实读案／工具／名单／署名安全区。不能简单把所有文字设allow-overlap，也不能把已隐藏文字永久取消交互入口。

优先保留DOM button和原生cluster source。若有充分证据迁移symbol，更改前核中文字体glyph、本地资源、命中与键盘路径，说明收益；本轮不强制增加服务、地图引擎或全站字体依赖。

### B：改聚合点击为渐进探索

使用锁定版本公开 `getClusterExpansionZoom` 等接口求下一分解目标，结合本次安全图面；自动聚合点击单次放大预算约2级，按实际数据验证。不得把此上限施加到原生手动探索11.5级。

一次点击必须有清楚结果：进入下一可理解的区域／分组，或者打开完整成员名单。跨太远才分解、同坐标、已到上限时用名单；不得反复无变化，也不得自动多段飞到最终最高倍。名单中选择地点复用现有read入口；如增加继续展开按钮，动作名称和含义明确。

目标实际路径：全国西北3 → 西北区域楼兰＋敦煌2 → 玉门关／阳关可识别或可选择；东部5／手机4 → 楼台与杭州近邻 → 两处完整名单。候选镜头包含文字边距，默认桌面约64px／手机40px，不以点恰好在边缘判合格。

整个流程可被手动拖缩打断。异步cluster结果校验源版本、当前成员及相机意图，旧点击不能在搜索／关闭／新点选后重新飞或打开旧名单。沿用看全国公共resize同步及最后一次命令机制。

### C：轻量题注与名单交互

先画全国、区域、近邻、选中四态小方案，用真实九地名称审查，再实施。普通标签改成墨字／轻护字，削弱统一矩形纸条；保留16px左右地名字号，数字聚合紧凑清楚。选中／焦点才加强短底及朱色，避免叠装饰。界面层级参照Anthropic，艺术取意继续赵佶／宋画细笔与纸地，不新增鹤、印章、纸污和三张同款画框。

区域短名由真实成员集中生成，完整名称在名单提供；泛“2处地点”不能冒充同城。所有成员有入口，作品数在名单准确显示。个体图标、数量聚合、当前选中三种状态可区分。

近邻名单的44px关闭、Esc、焦点恢复、滚动与工具避让统一处理；同坐标测试能直接选成员。键盘焦点即使普通文字曾隐藏，也能显示完整名称与可见焦点，不移动真实位置。保留搜索／主题条件与筛选外阅读协议。

不要让每次annotations刷新都重建按钮内部；保留名称节点、候选与样式状态。移动中跟随点位，停稳后稳定排布，显隐轻反馈约100–160ms且支持reduce。不要添加hover才能使用的唯一入口。

### D：新证据与交付

正式9点、隔离12点、40点都实测；测试配置明确非正式数据。主尺寸1280×720、1000×800、390×844；另检查600附近布局断点仅在本轮规则受影响时进行。

每项记录动作前后、稳定态、成员与必要中段；原生滚轮／拖动不能用map方法替代。读取公开诊断数据时，moving不是最终相机，截图尺寸要与实际viewport对应。不要复制旧矩阵改日期。
