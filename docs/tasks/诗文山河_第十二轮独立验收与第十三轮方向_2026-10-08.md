## 3. 保留的具体问题

### R01：跨尺寸、局部往返后的第一次全国复位

本次实际路径：1280桌面放大 → 打开杜甫长诗、案外缩放 → 关闭 → 搜索苏轼打开西湖 → 地点页进入局部再回全国 → 切390手机 → 回诗文、切《钱塘湖春行》 → 关闭 → 看全国 → 清除苏轼条件、关闭目录。

最后目录关闭后的公开状态已经是idle，但zoom为2.517159，而同页z0为1.827456。该状态的真实截图确有裁切，随后第二次看全国能回到正常总览；390冷启动也正常。另以“桌面打开西湖→390→关闭→立即看全国”的简化路径复测，最终正常。

因此，本次证据支持“一次真实组合异常”，尚不支持具体根因。不能把动作中的 `moving` 样本或旧画面当失败：原样本18、20、22是在动效中；截图08已是恢复后的完整图，不能用文件名误判。首次异常的正确证据是样本17与截图05。

下一轮在完整路径补新镜头／布局轨迹，核查关闭时探索恢复、全国复位、尺寸重测和安全区的执行顺序。若能复现，保证最后一次明确命令生效；若不能复现，保存完整路径两次稳定态证据及边界结论，不能随意加延时或修改引擎私有字段“治好”。

### R02：跨尺寸回读旧篇的语义位置

从西湖地点页切回苏轼旧篇时，390正文scrollTop为105.333px，首屏从诗中部开始；切到此前未读的《钱塘湖春行》则为0。这可能涉及已有回读记忆及尺寸变更后的语义锚点，不能仅凭scrollTop不为0判错。

下一轮补两条明确初始条件的回归：旧篇停在题名处／旧篇停在第二联处 → 地点页 → 改尺寸 → 回旧篇。题名状态应仍见篇名作者，第二联状态应恢复第二联；新篇从起点开始。失败才修阅读记忆，成功则保留现有协议，不强制每次换标签回顶部。

## 4. 美学与布局判断

**当前可以作为继续开发的视觉基线。** 轻页头、单一搜索入口、细省界与更清楚的文化锚点、读案一层柔和纸面，比此前明显减少矩形框堆叠。1280读案宽384px、1000宽360px；390读案宽366px、高约361px，留有可探索地图。原文、题名、工具各有角色，原文不被插画遮挡。

本次没有看到需要再重写“诗文／地点／篇目”结构的理由，也不需要继续加圆角、纸纹、印章和空白来证明宋代美学。全国地图的薄青与纸地、读案宋体和已有两画可以保留。它仍是现代文化地图的宋画取意，不能称赵佶笔墨复原；用户审美终审保留。

目前全国图显得空，主要因为正式库只有6处、东部集中，西北没有内容。手机全国有时合成“6处地点”数量组，地域辨识弱。优先用西北三个真实地点检验分组与标签，比继续改全站外观更有价值。

开发记录确有frontend-design读取路径、先方案后实现、两件馆藏原图观察和实际页面批评。此为可审阅的使用记录；不能仅凭skill名字判定美术通过。本次亦实际读取该skill并看了生产页面。
