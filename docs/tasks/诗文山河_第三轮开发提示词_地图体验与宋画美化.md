## 用户已授权底图二创

用户原话：“地图可以二创修改，注意标出原图与改动就行。”允许基于现有官方EPS/JPG制作衍生版，调整色彩、视觉线宽及信息层级。**旧任务要求运行地图绝对不改色、绝对原样，不再用于禁止本轮设计修改。** 原始JPG／EPS与原件哈希独立保留，不能覆盖；新资产另命名、另记录。

保留实际地理形状及必要的边界、岛屿表达。不手描／生成式重绘中国轮廓，不随意删岛、改线或以美术构图移动地点。可以整理非必要城市注记和制图版面，但要能辨认被处理的对象并记录，不盲目按所有小路径大小或颜色删除。

原图查看入口提供完整未修改图幅、原署名与原编号。衍生地图的来源说明写清“基于自然资源部标准地图原件制作的项目设计版”，原图GS(2023)2763是原件身份，不当作衍生版的新编号。不把来源介绍铺成主界面的技术长文。

## 1. 先验证衍生底图的可制作性

优先走 **官方EPS → 保留几何的中间矢量格式 → SVG衍生版**。先检查本机可用工具和字体；EPS含二进制预览头、CorelDRAW PostScript，不能当普通XML或用正则直接改。优先使用已有可信转换工具；若需要工具，选官方渠道并记录实际版本，工具选择不得发展成长期环境改造。

用约90分钟的可行性步骤验证：能否保持完整边界和岛屿、文字／路径是否完整、能否辨认背景与主要线层、SVG大小和浏览器渲染是否合适。保留转换命令／脚本及一张未改色转换结果，与原JPG并排检查。先验证正确性，再改色；必要时矢量处理后输出合理分辨率的静态图，没必要让数十万路径在每次拖动时参与DOM布局。

若EPS转换或分层不能可靠完成，本轮采用JPG的可复现显示颜色映射作为受限衍生方案：保持位置与像素对应，不抹掉注记、不猜分层、不使用整幅模糊滤镜掩盖问题。尽量将白底协调为素纸、紫灰线协调为淡墨；记录映射方式与无法解决的注记密度。变换前后对照检查边线与岛屿仍可辨，避免把边线一起变透明。这条路线可以先完成交互，但若密集注记仍显著影响观感，明确记录地图美术未完全达标，不能靠“加了纸纹”宣称完成。

无可靠配准依据时继续使用原图平面坐标；本轮不把SVG或图片伪装成经纬度地图。如转换后viewBox、画幅或边距改变，保存旧像素到新图面的变换并逐点核对现有城市入口。不要直接把旧百分比套到裁过的图上。

## 2. 地图本身的视觉改造

方向：**素纸上的淡设色山河，地点如题注，选中处如精绘小景。** 整体沿用 `#F4F0E6` 素纸、`#FCFAF4` 洁纸、`#2E3430` 墨、`#506553` 石青绿、`#A8BBB9` 水色、`#8D5044` 少量朱色。全国底图与界面连续，不再是一张白色海报贴在黄底页面上。

- 在能确认图层的矢量方案中，把突出的紫灰粗边／视觉晕边改成清楚但克制的墨青线。必要地理线条保持辨识，不能一律淡到不可见。
- 总览只让必要地理信息和文化地点突出；一般城市注记弱化或按尺度展示，文化标签保持清晰，详细原图仍可查看。不能把全部原有城市注记与新增地点同等强调。
- 地点标签采用简短地名与细小类型符号，触控热区至少44px。去掉现在贴在地图上的大块浅色矩形及过长引线；选中可用朱色小印记／细线加强，焦点另有清楚轮廓。
- 底色用微弱静态纸纤维，湖水淡设色、岸线有轻重。地图几何不随机抖动，不做旧纸污渍、破边、满屏水墨晕染。
- 赵佶方向取细察物象、工致线条、疏密与题诗关系。首页最多一幅小景；只在湖心亭／西湖选中时完善一幅与地点相符的小景或题注。装饰与真实地理分层，不画伪山脉和无依据路线填空。
- 正文继续清晰宋体。瘦金体只在已有文件且网页嵌入授权明确时用于站名或少量标题；没有合适字库沿用回退，不让找字体阻塞地图任务，不拿未知“免费下载”字体直接发布。

保留整体阅读面板的优点，只调整与地图衔接的边线、间距和标题主次；无需全站换皮、堆大圆角卡片或添加全屏开场动画。

## 3. 全国主地图的操作闭环

把现有只显示图片的区域改成可以探索的主地图画布。Panzoom负责图面手势，React负责应用状态；可将控制封装为 `OverviewViewport`，不要把全国图混进没有配准的L7地理场景。沿用L7／MapLibre的真实西湖局部。新增库负责哪个能力、项目代码负责哪个能力，在交付说明中写清。

实现以下行为：

1. 初始为完整全国视野，地图是页面主体。控制条有“放大、缩小、看全国”，不必另开原图弹窗才可探索。滚轮围绕指针缩放、鼠标拖动、触摸拖动／捏合；明确最小和最大缩放，不能把地图拖走后无法找回。
2. 文化锚点与地图共用变换；标签与热区维持屏幕上的合理字号和尺寸，不随放大变成巨大牌子。位置由统一变换计算，避免两套不同百分比造成漂移。用requestAnimationFrame或成熟库事件协调，不让每个pointermove触发整页重渲染。
3. 点击地点后，选中处进入阅读面板以外的可用区域，再开阅读；搜索选中也走同一入口。图面聚焦表达区域关系，不承诺街道级精度。
4. 关闭阅读恢复打开前的全国图面视野；进入西湖局部后返回全国也恢复该视野。控制条“看全国”才主动复位完整图幅。过滤、切作品、切沿革不重置地图。
5. 小位移点击与拖动分清，拖动结束不会误开地点。阅读面板、按钮、搜索和展开原文的滚动，不触发地图拖动／缩放。交互提示只给必要短句。
6. 保留每处实际图面锚点。杭州可低倍分组、高倍或点击展开湖心亭／西湖；苏州和扬州各用自己的锚点，不永久把两处锁在扬州的“江南”入口。依据屏幕标签碰撞决定分组／避让，不为排版移动地理锚点。6处不需要大规模GIS聚类系统。
7. 鼠标悬停／键盘焦点可出现地名、作者／一句短诗的预览；手机一次点击就能明确选择。近邻展开优先使用地图旁的小列表，避免每次盖住整个地图的模态弹窗。

支持键盘地点选择、缩放／复位按钮与Esc关闭当前浮层。尊重减弱动画：普通定位约300–600ms、阅读案约180–240ms；减弱时直接切换。不做自动巡游或持续飘动。

## 4. 西湖局部与响应式

沿用现有OSM湖岸、岛屿、堤道、L7地点和MapLibre相机，保留重要几何，不重新采集全部数据。水、岸、岛、堤形成层次；主要标签取舍与避让，湖心亭名称清楚且不把无意义的“杭州”尾注重复贴在近景标签旁。

按真实可用地图矩形fit bounds。地图内容大致占可用区域的55%–75%，不是占整个浏览器的比例；湖面与选中点不能被阅读案挡住。用户手动缩放／拖动后，切同一地点的阅读标签或作品不反复抢回相机；布局改变时只做必要避让。提供“回到西湖／定位此地”，恢复初始局部视野。

重点检查768–1024px：侧栏若导致地图剩余宽度不足，应采用底部阅读案或更窄的阅读布局，不照搬1440下约400px的侧栏把地图压成小块。390px默认底部半屏，地图可继续触摸；近全屏阅读有清楚返回方式。正文滚动、地图手势和浏览器页面滚动边界明确，不用全页touch-action:none粗暴禁用。

首次局部仍按需加载、随后一个实例复用。加载时占位稳定并给明确反馈，失败仍能读诗文和返回全国。不要让兼容桥调整或依赖升级挤占本轮主要工作。
