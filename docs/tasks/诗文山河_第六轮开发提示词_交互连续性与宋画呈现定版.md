## 工作包一：先修状态和焦点

依独立验收复现并修I01–I04；必须用真实界面操作确认，不只查源码。

- **阅读记忆。** 湖心亭读到原文中段，切此地／沿革再回诗文，原文开合与阅读位置恢复。按placeId／workId／tab保存，至少在当前会话内成立；首次新作品合理从起点读，换回已读作品恢复其位置。同地点换篇不改变相机。展开／半屏也保留内容锚点。删除`[tab,work.id]`无条件归零的行为，处理画隐藏、正文高度和容器尺寸变化；不要只是把一个全局scrollTop套给所有内容。
- **稳定换篇入口。** 当前作品和备选作品采用稳定节点与清楚选中状态，或换篇后明确转移焦点到新篇名。Enter换篇后焦点不能落body；题名、引句、解读、全文高亮和来源同步；保留第五轮全文展开策略。页面内换篇去掉外链↗语义。
- **浮层优先级。** 原生资料dialog／移动目录覆盖在上层时，背后地图tooltip／分组不得抢Esc。关闭只影响顶层；焦点回正确入口。覆盖型目录与来源互斥，不增加复杂多层modal。桌面并列目录继续不锁全页。
- **地图分组键盘路径。** 键盘打开江南／同城组，进入首个可选地点；Esc／关闭回原组按钮；选项选中进入该地点。支持合理Tab顺序，不把组选择面板误做全页模态。分组入口消失时有合理后备焦点。
- **全国与局部的两份记忆。** 自由探索视野用于退出阅读；进入局部前的全国阅读视野用于回诗文。重入局部保留手动镜头；开目录、出处、换篇不重新聚焦。避免所有resize／tab变化都被解释成新的选点。

允许抽出小型阅读状态／导航／浮层控制模块，职责清楚；不先引入大型状态框架。不要以新增一层CSS补丁代替状态修正。

## 工作包二：让连续操作真正流畅

按交互与动效规范的矩阵实施，先做阅读案进入／退出、手机半屏↔展开、目录／出处过渡、地图镜头接管；高频换篇与标签可以即时更新或极轻淡入。

1. 同一阅读案移动端从底部、桌面从右侧进出；开合方向一致。稳定的标签与工具骨架不随长诗或画的存在跳位。
2. 点选立即反馈，内容真实ready就显示；没有等待式开场、固定补足loading或每次成功toast。
3. 最新操作优先：选点A过程中点B、展开过程中收起、开案中关闭、连续换篇，结果必须是最后意图；没有旧动画回写、延迟复活、重复镜头队列或整站锁定。
4. 用户拖动立即接管正在进行的镜头；已有420ms动画与RAF文化锚点同步机制复用并检查。移动中的点、文字与底图不能各走各的。
5. 减少动态与站内静观完整生效；状态完成和资源清理不依赖animationend。关闭的浮层在退场阶段不留下可聚焦控件。
6. 优先合成层transform／opacity；严查高度过渡是否触发每帧地图resize／fit、重新聚焦或L7重建。不要缩放整块文字伪装展开，不用全屏毛玻璃解决跳动。

在改变受影响组件时整理相关样式归属，避免继续在styles／exploration／song-design三处叠同名覆盖；仅整理必要范围，不做全项目格式化和顺手重构。

## 工作包三：定版宋画构图，再统一全国与控件

先做湖心亭（诗画／长文）和黄鹤楼（无画／两篇切换）两个实页。在1440、768、390三尺寸验证后，将同一规则推广到六地点、目录、出处和局部工具。

- 全国图是主卷，阅读是侧页／展开纸案；纸色、留白、题名、题注和墨色是统一关系。阅读外缘避免硬框和重阴影主导，柔和通过材质、边缘层次与构图实现。
- 阅读骨架采用稳定的返回／展开、地点与区域、三个内容入口；当前标签被上方内容推来推去的布局允许重排。手机半屏先能识别地点、作品并切标签／作品，不被插画吞掉操作空间。主要操作可读且44px命中区，颜色克制仍有明确焦点。
- 湖景与题诗形成册页关系，疏密与诗意关联。主物象在240–420px实际宽度有细节、墨线主次和设色体积；普通低饱和水彩、纸底发黄、背景噪点不能代替赵佶主轴。保留第五轮优点，必要时只修这幅样板一次；黄鹤楼不用错误湖景，也不复活工程线稿。
- 地图文化地名是第一层、原图城市注记第二层、工具第三层；明确选中锚点与地名，避免靠所有文字变淡制造温柔。重新看工具位置、图面比例、目录开合与选中状态，减少同时争夺视线的元素。正文保留清晰HTML，题名不生成进图片。
- 保留原纸墨配色，不引入新整套主题、玻璃UI或夸张弹簧。纹理静态且适度；不批量加鸟、印章、卷轴、装饰线来证明“宋代”。

全国v5a是本轮输入；不要继续无目标地做第三、第四组调色候选。用户授权二创且必须标原图与改动；任何素材变化独立另存、更新hash和台账，保留官方JPG／EPS及旧设计版。不能用AI生成地图、整体模糊、变形或抹掉地理信息改善观感。

EPS复用已有可行性结论；工具条件没变化不再下载／安装Ghostscript或换通道重试。只有新增可信条件时按总计划最多2小时一次验证，否则直接记录本版PNG路线。现有PNG密注记／边线不能独立编辑的限制如实保留，**格式限制不能自动授予地图视觉通过**。

从`docs/planning/release-scope-v1.json`取12处主流现代位置做隔离布局压力检查，覆盖玉门关／阳关／楼兰近邻及山海关等新区域；需要的新图片锚点只能放在测试配置并标“规划布局”。检查分组名不把全国所有新近邻都硬编码成“江南”；选中地名单独可辨。正式页面继续6／8，新增锚点入正式库留阶段C。

## 工作包四：验证与交付

先做针对性回归，再执行数据／设计检查与生产构建。第五轮完整矩阵复用，只有被改动影响或失败的路径才扩测；旧截图不能冒充新实现的证据。

| 必验动作 | 可验收结果 |
|---|---|
| 长文中段→此地→诗文／沿革→诗文 | 内容锚点与原文开合恢复；相机恢复规则一致 |
| 黄鹤楼与西湖键盘换篇，再换回 | 焦点始终可见可用，来源对应当前作品，已读篇位置恢复 |
| 半屏→展开→半屏，含过程中反向 | 内容无归零、无文字缩放闪动、无隐藏残留焦点 |
| 江南组→出处→Esc，以及目录／阅读Esc | 仅顶层关闭，焦点回入口，不被背后预览抢夺 |
| 快速选A→B→关闭，重复至少10组 | 最后意图生效，无旧画面复活；退出恢复最早探索视野 |
| 动画途中手动拖动／缩放 | 用户接管，标签与锚点保持对齐，无过时镜头覆盖 |
| 局部往返与缩放 | 同一L7组合实例，不因过渡重建；手动局部镜头保留 |
| 静观与OS减少动态 | 无持续位移动画，所有状态／滚动／焦点行为仍成立；未实际测OS项须注明 |
| 三尺寸及12点隔离布局 | 6／8正式页面无溢出；文化点可辨、组可操作；规划点测试不混入运行库 |

交付三尺寸同状态前后截图，另有连续录屏或带时间戳的连续帧／状态轨迹，能够看见快速反向与切换的过程。记录本机性能采样方式、设备和实际停顿；不虚写稳定60FPS，不用终态截图证明动画中锚点对齐。实体手机能测则测；没有设备就保留未测，不以390px模拟替代双指验证。
