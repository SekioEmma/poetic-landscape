## 2. 第一版成品的固定范围

一句产品定义：**从一张中国地图进入诗文中的山河，选择地点读经典，再按资料条件查看局部地理、真实图景与短沿革；用两卷主题阅读组织一段可完成的文化体验。**

进入时地图为主、详情关闭；目录按需打开。没有等待式开场动画。3分钟示范能够展示：自由选点→读名句和完整原文→湖心亭局部／照片→返回探索→主题卷推进／退出。

## 3. 固定技术与交互约定

### 已验证的底座继续使用

React 19.3.0、Vite 8.3.2、TypeScript 5.9.3、L7／l7-maps 2.29.1、MapLibre 6.12.0、Panzoom 4.6.2及现有lockfile组合保持。MapLibre兼容桥涉及内部字段，只对已测组合负责；没有明确需求不升级依赖。

第十一轮主路线为**现有锁定L7／MapLibre＋来源明确的全国底图＋实际坐标文化点**。官方EPS可用才整理为矢量资产；不可用直接实施L7全国地图，本地GeoAtlas技术样板与正式发布来源资格分开。可用授权矢量资料或天地图分级服务替换底图；服务返回PNG瓦片时如实称栅格瓦片。原PNG／Panzoom保留为历史输入和故障降级，不是下一轮正式主模式。EPS纸面XY、WGS84、GCJ-02不得混称或混用，源数据不覆盖。

全国允许更换地图控制与相机适配，调用者改用地理镜头接口，保留探索／阅读／局部视野协议及全文阅读位置。优先复用一个L7／MapLibre组合；若确需两个则懒创建、不累加，非活动实例暂停。原件JPG／EPS、照片、源几何、来源及历史证据保留；新路线需要新检查，旧PNG字节冻结只约束历史资产，不阻止新增底图。

### 先稳定导航协议，再增加主题状态

| 操作 | 本版约定 |
|---|---|
| 探索→选点 | 保存探索视野，选地点及关联作品，进入自适应常态诗文；短高度无法同时看图与读文时用明确收起题签；最后一次选择优先 |
| 切作品 | 全文默认可读；完整篇名与作者识别选择；当前地点与相机不变，题名／全文／高亮／解读／底本同步；新篇从起点，回读恢复位置，焦点保持上下文 |
| 诗文／地点 | 两视图各记位置；原文优先，地点简介与沿革同页；切地点不自动切地图。明确局部入口才进入L7，重入保留手动镜头，回全国恢复阅读视野 |
| 收起／常态／专注 | 同一案保留作品／视图／语义锚点；收起保留选点和手动镜头，继续恢复；专注仅由明确操作进入。关闭才退出并恢复探索，清理模式／动画／隐藏控件，维持R01修复。布局与安全区共享判断 |

| 进入主题卷 | 保存自由探索的视野和筛选，主题临时使用完整章节结果；章节调用与自由选点相同的选择入口 |
| 切章／手动拖图 | 切章联动指定地点与作品；手动拖动后暂停自动跟随；继续跟随回到当前章 |

实现时可抽出小型选择／视野控制接口，避免重复导航逻辑；无需大型状态库。图库、正文与地图不能各自保存互相冲突的当前作品。会话记忆、浮层、焦点与动效继续采用[交互与动效规范v1](G:/project/数媒/design/诗文山河_交互与动效规范_v1_2026-10-06.md)；其中三标签、固定作者栏、全文折叠和画先于原文规则由[地点阅读规范v1](G:/project/数媒/design/诗文山河_地点阅读信息架构与版式规范_v1_2026-10-07.md)覆盖。第八轮以[地图与读案空间规范v1](G:/project/数媒/design/诗文山河_地图与读案空间规范_v1_2026-10-07.md)覆盖旧面积数值、宽度单断点与选点即占64–68dvh规则，其余内部阅读协议保留。Google Maps用于窄详情与收起逻辑，Apple用于连续、可预测与及时反馈，视觉继续纸色和宋画。
