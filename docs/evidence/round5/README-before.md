## 启动

Node22.12+的兼容版本，依赖由lockfile锁定，不需API密钥。开发及预览使用本地数据、地图worker和照片。

```powershell
cd 'G:\project\数媒\poetic-landscape'
npm ci
npm run dev
```

开发：http://127.0.0.1:5173/ 。生产检查：

```powershell
npm run check:data
node scripts/check-overview.mjs
node scripts/check-design.mjs
npm run build
npm run preview
```

生产：http://127.0.0.1:4173/ 。固定端口，已有服务占用时先停止原服务；Ctrl+C停止。第四轮静态包在releases/诗文山河_第四轮静态包_2026-10-06.zip；旧轮包独立保留。静态包须HTTP服务，不能双击HTML。制图Python仅用于重新制作／检查资产，不是运行页面的依赖。

## 探索与阅读

- 在主画布拖动，滚轮围绕指针缩放；放大、缩小、看全国按钮可用。近邻点按屏幕距离展开地图旁短列表，杭州分别选择湖心亭与西湖，高倍苏州／扬州各自可选。
- 全国手动探索→选地点→此地→诗文→关闭，恢复选中前的全国视野；看全国单独复位。搜索作者时优先对应作品，过滤和作品切换不重置地图。
- 此地沿用L7／MapLibre的真实西湖；第一次进入才加载，随后一个实例复用。手动调整局部后切同地点标签保留镜头，“定位此地”恢复初始范围。
- 768–1024与390底部阅读可展开、收回；正文独立滚动。键盘地点、缩放、标签左右键与Esc可用；出处可启用静观。触摸捏合为Panzoom能力，本轮未做实机或双指模拟验证。
- 原图与改动、完整原图查看均可查。原图、设计图或局部失败仍从目录阅读。

测试入口：`/?overviewFail`、`/?originalFail`、`/?mapFail`注入三种失败；`/map-lab`保留独立L7验证入口，正式全国不显示测试几何。
