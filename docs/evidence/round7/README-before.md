第六轮完成当前6地点8作品的阅读记忆、键盘换篇、浮层优先级和连续操作收尾。阅读工具／地名／标签与作者题签固定，正文单独滚动；湖心亭题诗与已有湖景相邻，390半屏先见地名、篇名作者与引句。半屏展开从当前纸面位置接续；拖动立即接管全国镜头，最新操作取消旧动作。

## 启动与检查

Node22.12+兼容版本，依赖由lockfile锁定，页面无需API密钥。源数据、地图worker、画与照片本地打包。

```powershell
cd 'G:\project\数媒\poetic-landscape'
npm ci
npm run dev
```

开发：http://127.0.0.1:5173/。生产检查：

```powershell
npm run check:data
node scripts/check-overview.mjs docs/evidence/round6/overview-math-check.json
node scripts/check-design.mjs
npm run build
npm run preview
```

生产：http://127.0.0.1:4173/。两端口固定，Ctrl+C停止。静态包[第六轮ZIP](releases/诗文山河_第六轮静态包_2026-10-07.zip)为dist全部文件，根index.html，须HTTP服务；不能双击HTML运行地图。绘画已打包，运行不需调用imagegen；Python仅用于重做／检查地图资产。

## 操作与范围

- 全国可拖动／滚轮／＋−、选地点或近邻组。当前地名独立于组；看全国复位相机，返回中国地图退出阅读并恢复选中前探索视野。
- 寻诗文支持地点、别名、作者、篇名及主题。搜苏轼／茅屋／枫桥优先对应作品；旧阅读与新筛选分开标示。覆盖目录与来源互斥，Esc只关顶层；桌面目录仍可并列。
- 阅读按地点／作品／标签保存当前会话内容锚点；全文展开沿用同地点共享策略。键盘Enter换篇，作者入口保持焦点；长文中段切此地／沿革再回诗文仍可续读。展开后容器变高可能夹取末尾位置，不无条件归零。
- 此地首次按需加载局部图，随后复用一个组合实例；重入保留手动局部视野。湖心亭实景仍显示摄影、日期、CC BY-SA4.0与未修改说明。已有湖景明确为AI辅助原创意境，非实景或古建复原。
- 出处可开启静观。`/?overviewFail=1`和`/?mapFail=1`为失败注入检查，目录和HTML原文仍可读。
- `/layout-lab`仅为12点规划布局压力页；不含新增诗文，也不写入正式content。新图片参照仅为城市区域入口，正式景区锚点与发布审核留阶段C。
