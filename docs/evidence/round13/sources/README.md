# 来源归档的公开范围

archive.json 保留第十三轮原始抓取时间、URL、HTTP 状态、字节数和 SHA-256；完整 HTML 保留本地，因页面现代文章及站点代码的再分发条件未落实，不进入公开仓库或静态包。403 响应不作为核读依据。

public-domain-poems.json 仅保存四篇已核读的公版古诗及出处，上传准备时逐项核对本地 HTML 哈希与完整古诗；不包含现代解读、译文或整篇网页。

check:data 在有本地 HTML 时检验源档哈希和全文；克隆仓库缺少 HTML 时检验冻结的古诗摘录和来源元数据，输出明确区分两种路径。此路径不会重新下载或重新核读网页。SOURCE_ARCHIVE_MODE=public-extract 可强制验证克隆路径。历史内容核读记录仍表示当时的本地核读。
