第五轮完成6地点8作品的交互整顿与湖心亭／西湖绘画样板：阅读时取消地图重复诗卡，作品切换靠近篇名作者、标签在画前、全文操作显示实际状态；390/768覆盖目录隔离背景焦点、循环Tab并返回触发按钮，1440目录与阅读并列。AI辅助原创冬日湖面画有远亭、舟、疏岸与淡设色，独立于真实地图和照片。

## 启动与检查

Node22.12+兼容版本，依赖由lockfile锁定，页面无需API密钥。源数据、地图worker、画与照片本地打包。

```powershell
cd 'G:\project\数媒\poetic-landscape'
npm ci
npm run dev
```

开发：http://127.0.0.1:5173/。生产检查：

```powershell
npm run check:data
node scripts/check-overview.mjs
node scripts/check-design.mjs
npm run build
npm run preview
```

生产：http://127.0.0.1:4173/。两端口固定，Ctrl+C停止。静态包[第五轮ZIP](releases/诗文山河_第五轮静态包_2026-10-06.zip)为dist全部文件，根index.html，须HTTP服务；不能双击HTML运行地图。绘画已打包，运行不需调用imagegen；Python仅用于重做／检查地图资产。

## 操作

- 拖动／滚轮或＋−探索全国，地名和动态组可选；杭州组分别进入湖心亭与西湖。看全国只复位相机；返回中国地图退出阅读并恢复选中前视野。
- 寻诗文支持地点、别名、作者、篇名及主题。搜苏轼／茅屋／枫桥优先相应作品；地图与目录同一结果集，旧阅读与筛选结果明确区分。手机目录覆盖时背景不可聚焦，Esc只关目录；选择后聚焦地点标题。
- 阅读半屏优先地名、篇名作者与引句，展开继续读。多作品的“另读”文字入口在画前。诗文／此地／沿革保持可见，全文可展开、收起，换作品保留其状态。
- 此地首次按需加载L7／MapLibre，随后复用一个实例；同地点切标签保留局部镜头，定位此地复位。湖心亭照片仍有Bjoertvedt、2017-07-21、CC BY-SA4.0与未修改说明。意境画明确标为AI辅助原创，不替代照片或地理。
- 出处有原图链接、实际改动、当前作品底本、坐标系与文化来源，另可启用静观。`/?overviewFail`、`/?mapFail`只用于注入失败回归，失败仍可从目录阅读并返回；不是硬件故障模拟认证。
