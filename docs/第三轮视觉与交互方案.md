# 第三轮视觉与交互方案

2026-10-06。依据任务书、赵佶视觉规范及frontend-design官方原文的方法；未安装该skill。设计焦点是可操作的真实山河，保留既有配色及宋体阅读，不借通用模板换皮。

素纸#F4F0E6承接地图，洁纸#FCFAF4承接阅读；墨#2E3430、石青绿#506553用于必要线与文字，水色#A8BBB9用于湖面，朱#8D5044只标选择。原图与衍生图分开，采用逐像素可复现映射，不改变画幅、地理形状或锚点；EPS转换没有可用工具且官方Ghostscript安装被自动审批拒绝，受限路线不能降低所有密集注记的数量。先对照原图检查颜色与岛屿，再实施交互。

全国画布以完整图幅起步；拖动、围绕指针缩放与捏合复用Panzoom。项目只处理锚点变换、标签碰撞、面板安全区定位与视野保存。标签为地名题注，44px触区与不缩放的文字跟随同一矩阵；苏州、扬州各保留锚点，碰撞时临时合组并在旁边展开短列表。杭州同城始终可分别选两地点，不用全屏弹窗。悬停与键盘焦点显示短诗，选中用朱点与下划线。

阅读前保存探索视野；聚焦选中地点到安全区，再展开阅读。全国→阅读→局部→全国与关闭阅读都可恢复先前视野；“看全国”单独复位。过滤、作品与沿革不重置镜头。普通定位420ms，减弱动画0ms；手势期间以帧同步DOM变换，不整页更新。

```
1440：站名                       寻诗文 / 出处
      简短引导   [可拖动山河，题注] │阅读案（选中后）
      一幅小景   [缩小 放大 看全国] │诗文 / 此地 / 沿革
768： 站名                 寻诗文
      [完整宽度山河，安全区聚焦]
      [底部阅读案约45%高度，可展开]
390： [山河与44px题注，局部可触摸]
      [半屏阅读案，可展开至近全屏并收回]
```

西湖用既有湖岸、内环与堤道，水填色与岸线轻重区分，岛屿保留。按可用地图矩形fit到约65%，控制“定位此地”恢复；作品和标签切换不抢镜头。只在西湖／湖心亭阅读标题旁留小型湖上题景，明确为艺术点景；没有新实景照片或未授权字体。

自评重点：原白海报边界消失、文化标签先于城市注记被读到、图面能直接探索；若映射仍不能改善城市密度，明确标为美术未完全达标。以三尺寸同状态真实截图对照，不能拿设计稿替代运行证据。
