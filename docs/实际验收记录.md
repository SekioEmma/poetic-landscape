# 诗文山河 · 首轮实际验收记录

日期：2026-10-05。范围为首轮开发提示词与随后官方底图接入要求。源码、锁文件、生产静态包及来源记录均已交付；未公开部署。本记录对应 **GS(2023)2763 官方原图接入后的最终页面**。

- Windows 11 家庭中文版 10.0.26200，AMD Ryzen 9 8945H / Radeon 780M；Node.js 22.17.0，npm 10.9.2。
- 实际使用 Codex 内置浏览器操作开发服务 `127.0.0.1:5173` 与生产预览 `127.0.0.1:4173`。浏览器精确版本未暴露，未据此声称跨浏览器兼容。
- 界面操作、只读DOM尺寸/状态检查及目视截图：`evidence/official-browser-acceptance.json`。脚本构建与数据检查：`evidence/final-build.txt`、`evidence/final-data-check.txt`。
- 依赖版本与许可：`evidence/package-versions-verified.json`、`evidence/dependency-licenses.json`。`npm audit`结果为0项已知漏洞，见 `evidence/npm-audit.json`，不等同安全审计。
- 早期 `evidence/browser-acceptance.json` 和不带 `official-` 前缀的截图属于官方原图接入前的候选阶段，不能用于宣称最终全国底图通过。
- 静态归档：[诗文山河_首轮静态包_2026-10-05.zip](../releases/诗文山河_首轮静态包_2026-10-05.zip)，7,828,917字节。已检查归档根目录index.html、全部本地数据/图片/worker/许可文件，并从归档流重新计算官方JPG哈希，与原件一致。归档SHA-256为 `dd4b170d36725accd571c7d3b903af325be700409b471bcbfea692f56c4894ef`，详见 `evidence/delivery-manifest.json`。
