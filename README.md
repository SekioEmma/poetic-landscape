# 诗文山河 · 自由探索

在中国地图上寻一处山河，读与它有关的诗文。React + TypeScript + Vite，局部地图使用 AntV L7 与 MapLibre。

第二轮实现 **6个可阅读地点、8篇完整作品**：湖心亭、黄鹤楼、杜甫草堂、西湖、寒山寺与枫桥、瓜洲渡。每篇有作者、完整原文、关联句高亮、原创短解读与底本；每地有风物介绍和文化沿革。支持地点／别名／作者／篇名搜索、主题筛选和多作品切换。

全国首页采用用户提供的官方完整原图，原底图审图号 **GS(2023)2763号**，1∶1000万，对开、界线版、无邻国、线划一。原始JPG与EPS留存，运行JPG字节不变，不裁切或改色。城市参照按钮与标签为项目叠加，杭州组分别选择湖心亭、西湖，江南组选择苏州、瓜洲。全国图片入口不是经纬度配准。

首页不初始化WebGL。第一次进入湖心亭或西湖的“此地”时加载局部地图，之后复用一个实例；返回总览或切到其他地点时隐藏并清理局部状态。湖心亭保留2017年实景照片及许可署名，西湖复用已存档的现代湖岸与堤道。地图失败仍可从目录阅读。

## 启动

本机：Windows 11、Node.js 22.17.0、npm 10.9.2。使用 Node.js 22.12+ 的兼容版本；依赖以 `package-lock.json` 为准，不需API密钥。

```powershell
cd 'G:\project\数媒\poetic-landscape'
npm ci
npm run dev
```

开发地址：[127.0.0.1:5173](http://127.0.0.1:5173/)。按 Ctrl+C 停止。

```powershell
npm run check:data
npm run build
npm run preview
```

生产预览：[127.0.0.1:4173](http://127.0.0.1:4173/)。脚本使用固定端口及 `strictPort`，占用时先停止已有服务。`dist/` 是本地生成的静态包；第二轮ZIP在 `releases/`。需要HTTP服务，不能直接双击 `index.html`。运行地图数据、worker、照片与纸纹均在包内；出处链接和首次安装依赖需要网络。本轮没有公开部署网站或启用GitHub Pages。

## 一次体验

全国图“杭州” → 湖心亭 → 展开完整原文 → 此地 → 展开真实图景 → 沿革 → 返回中国地图。也可用顶部“寻诗文”打开目录，搜索“苏轼”后选择西湖，切换到白居易，再看西湖局部；搜索“茅屋”“枫桥”可直接找到相应地点。

手机支持半屏与近全屏阅读、长文滚动；桌面与768px保留侧边阅读。标签页支持左右方向键，正文可用键盘滚动，Esc关闭阅读或目录；出处中可设置减弱动画。无内容的“关山与家国”主题本轮禁用并说明。

独立验证入口：`/map-lab`（L7点／线／面测试）、`/?mapFail`（首次局部进入时注入初始化失败）、`/?lifecycle`（挂载／卸载检查）。测试几何不进入正式总览。
